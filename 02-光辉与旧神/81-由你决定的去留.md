# 由你决定的去留

从巢穴下山以后，众人先送圆雅回家，向等候的村民说明巨龙已经离开。安洁妮替圆雅检查过，又问她平日的病情和正在服用的药。圆雅便把此前求医的经过，以及医者对余下寿命的估计，一并告诉了她。

艾萨斯一直等在旁边，听完便望向安洁妮。

“她的病，你能治好吗？”

安洁妮没有马上作答。她又问清几处情况，才放下圆雅的手。

“我现在还没有办法保证。”她说，“今晚先让她休息。她以前用过哪些药、看过哪些人，也请你们记下来。我会替她向认识的人打听，有消息就托公会送来。”

艾萨斯点了点头，接过药物，记下服用的方法。圆雅向安洁妮道谢，仍惦记着母亲的药有没有备好，直到听见都已经安顿妥当，才肯躺下。

安洁妮随后又去看过她的母亲，留下药物与服用的叮嘱。露菲雅在门边等着，听见艾萨斯放轻脚步走回圆雅身旁，没有开口催他出来。龙已经离开，圆雅却仍要面对原来的病；他们救她回来，并没有换到传闻中的长生。

等母女两人安顿下来，露菲雅才与安洁妮离开。艾萨斯送她们到门边，又回屋看着圆雅服药；露菲雅没有再多留，与安洁妮回住处歇下。

第二天早上，两人收拾好行李，出门时村里已经有人在拆选拔会留下的布置。昨天被撞倒的桌椅也扶了起来，人们一边收拾，一边谈论巨龙离开的事。

杰斯特、欧琳与马修已在村口等着。他们得返回桑德拉，向女王报告村庄的情况，露菲雅与安洁妮便先走过去，同几位旧友道别。

马修说，果然只要露菲雅在，便不会缺事情。

露菲雅立刻要马修再说一遍，杰斯特赶紧拦住。明明过一会儿又要分开，何必非在临走以前，再把原本可以好好说的几句话变成争吵？

等杰斯特将两人劝住，欧琳才有机会问露菲雅接下来的打算。露菲雅与安洁妮仍要往未知的大陆继续走，原先的路不见得走完，新的消息也还会来。欧琳听完，祝她们一路顺利。露菲雅道过谢，又望了望几人身后，想起夏露露怎么没来。

欧琳说，她昨天已经走了。

纯白角饰的真相打击太大，大概也没心情留下听别人再笑一次。露菲雅想象那副神情，难得没有非追去补上一句，只说，倒真像她会做的事。

杰斯特等人告辞以后，露菲雅站在村口，目送他们沿路走远。安洁妮整理好背包，正要问搭档是不是也该出发，便看见圆雅与艾萨斯从村里走来。

圆雅歇过一夜，脸色仍有些苍白，走得也慢。艾萨斯陪在她身旁，到了近处，圆雅便向他轻轻摇头，自己走到露菲雅面前。

“昨天的事，谢谢你。谢谢你来救我。”

露菲雅摇头，说要谢便谢艾萨斯。圆雅望着她，停了一会儿，才告诉她，欧琳已经说过他们的过去。

“昨天以前，我不知道还有人在找他。”圆雅说，“他醒来时，只记得自己的名字……”

她没有继续替自己解释。露菲雅的手指慢慢扣住背带，原本想说没关系，又发现这三个字并不像平时那样容易出口。

圆雅说的是实情。她当初面对的只是一个倒在郊外的伤者，不知道那个人曾保护过谁，也不知道另一头有人怎样找了他一年。

露菲雅曾想过真正找到艾萨斯时，会有多少话要说，自己可以先发脾气，再问他是否知道这段日子怎样过来。她还想过，即使旁边有人看，也要让他知道，自己不是能够被一句太危险了就留在原地的女孩。

如今，艾萨斯就站在不远处，却仍想不起那些往事。露菲雅准备的那些话，不能因为自己终于想好，便要求他照原来的方式回答。

她望着眼前的圆雅，也说不出责怪的话。圆雅救过艾萨斯，照顾过他，在自己同样生病的时候，仍将倒在路边的人带回家。那些日子发生在露菲雅不知道的地方，却同样是艾萨斯真正经历过的生活。

安洁妮轻轻叫了声“露”。露菲雅没有立即转头，只先向圆雅摇了摇头。

“我没有怪你。你救了他，这件事，我还该谢谢你。”

圆雅抬起头，露菲雅也终于松开攥紧的背带。

“现在，你比我更需要他。他是你救回来的，这些日子，也是你在照顾他。”

她说完，仍停了片刻。心里当然难过，那些为重逢准备的话也仍然想说，可艾萨斯连过去都还没能记起，她又怎么能催着他立刻回到自己身旁。

“不过，他要留在哪里，还是得自己决定。”露菲雅看了不远处的人一眼，“我不能替他答应，也不能替他拒绝。你也这样想，对不对？”

圆雅点了点头，又望向站在旁边的艾萨斯，像还有话想说。露菲雅却暂时不想再谈下去，她重新提了提背包，向圆雅道别，转身招呼安洁妮出发。

两人刚走上村外的道路，身后便传来艾萨斯的呼唤。

“露菲雅！”

露菲雅停下脚步，回头看见他正从圆雅身旁赶来，便抬手示意，让他不必再往前送。

“圆雅还在等你。”她站住，却没有再朝他走过去，“她和母亲都需要照顾。你先回去，别急着跟上来。”

艾萨斯望着她。露菲雅知道，他未必全明白自己的意思，又放缓了声音。

“我没有生你的气。只是……现在你在她身旁，会更好一些。”

艾萨斯停在路边。他想向她道谢，又想解释自己并没有忘记她这次的帮助，可这些都不能代替她盼望着找回的过去。他仍不懂那些旧日的感情怎样发生，只知道这名女孩为了自己找了很久，如今终于见面，却还愿意先让他留在需要照顾的人身旁。

“谢谢你，露菲雅。”

他没有为了回应她的难过，便承诺下一刻就会放下一切跟上。露菲雅听清后点了点头，也没有趁他道谢，再追问一句究竟什么时候才能记起来。

说完以后，艾萨斯仍望着她。他知道圆雅救过自己的命，也渐渐明白，露菲雅虽然盼着自己恢复记忆、与她同行，却仍然愿意让自己决定该怎样走。

露菲雅将一直垂在身侧的手抬起，向他挥了挥。

安洁妮已走到身旁，没有催，等她自己将目光从村口移开。两人沿原来的道路往前，露菲雅起先走得快，后来渐渐慢下来，终于不必再装作这次不过也是轻松完成的一项委托。

走到村庄被身后的树木遮住，露菲雅才停下，回头望了一眼。纯白角饰没有拿到，找了很久的人终于见到了，也没能与她一道上路。她知道自己不该催艾萨斯立刻同行，可真走到这里，还是觉得难受，忍不住想再同他说几句话。

安洁妮没有拉她继续赶路，只看了看路旁能够歇脚的地方。

“要不要坐一会儿？”

露菲雅点头，解下背包放到脚边，在路旁坐下。安洁妮也跟着坐下，没有立即开口。

露菲雅将手掌压在膝上，看向村庄所在的方向。艾萨斯曾经等过她那么久，若接下来轮到自己，她也愿意等。她没有把握需要多久，更不能保证明天再想起时就不难过。可那份喜欢仍在，找到他时的高兴也是真的，并不会因为今天没能同行，就忽然全都不值得了。

安洁妮没有追问她还要等多久，也没有保证两人很快就能重逢，只将水囊递了过去，在旁边陪她坐着。

露菲雅喝过水，将水囊递回，重新背好行李。她慢慢系紧背带，没有立刻催安洁妮起身。

她曾以为，只要找到艾萨斯，便能把分开的日子接回去。如今终于见到了，才知道那些日子已经在两人身上留下不同的东西。她记得的过去仍然珍贵，圆雅救下他、陪伴他的日子，也已经成为他生命的一部分。

村庄里还有两个病人需要照顾。想到艾萨斯接过药物、认真记下用法的样子，露菲雅垂下眼，缓缓松开了攥着背带的手。

她当然还盼着他想起自己。可在那以前，她也希望他能好好活着，过完每一个尚未记起她的日子。

“走吧。”

声音比平日轻些。安洁妮起身走到她身旁，两人沿着村道继续往前。露菲雅没有再催快脚步，直到身后再听不见村中的人声，才低下头，轻轻擦了一下眼角。
