# 诊察册上的期限

翌日清晨，费特准备去涵洞接姐妹回营地。布琪昨日已经缓过来，接下来在营地调养，也方便同伴照顾。

聆烨已经坐在桌边，核看昨日带回的记录。费特过来同她说起接人的安排，她点头应下，将身旁的位置让出一些，请他坐下喝杯茶。

琉特替她放好图纸。依莎与十三也在桌边坐下，青江菜提来热水，银狐便伏在她脚边。梅梅和亚岁正在另一间屋里整理写给家里的信，没有过来。

聆烨将几份记录按年份排好。琉特帮她整理随身的册子时，将那本宫中医者留下的诊察册也放到了桌上。她看了一眼，伸手将它拿起。

聆烨将诊察册翻到最后一次记述的地方，指尖停了一阵，才抬头望向同伴。

“还有一件事，之前只同琉特说过。”聆烨望向同伴，“你们既然留下来帮我，也该知道我的情况。”

依莎停下翻纸，费特也坐近了些。

“我身上的力量，有一个二十年的循环。”聆烨说道，“人类的身体承受不住那么久。到了极限，本源还会延续，却要换一具身体承载。可现在的记忆、性情，不一定能留下。”

十三手里的笔停在纸上。青江菜望向公主，扶着水壶的手慢慢收紧，却等她先说完。

“医者原先说，我剩下不到一个月。第一次来这里时，守护者借世界树的力量，替我疏缓过，才多争取两三个月。”聆烨说道。

“已经暂缓了，现在还会难受吗？”依莎轻声问。

“比以前好。只是暂缓，不是已经解开。”聆烨答道。

青江菜将热水放到她手边，目光仍停在那本诊察册上。

“那以后怎么办？”青江菜轻声问。

“眼下还没有办法。”聆烨将册子合上，“先把泉房和朝中的事查清。那些工房还在用人施术，不能继续拖着。”

琉特看着她收好诊察册，没有劝她放下手头的事，只将尚未看完的工房记录移近。

桌旁忽然传来一个声音。

“殿下，古墓里的事，我还有些没有告诉你。”

青江菜回过头。银狐朝梅梅和亚岁所在的房间望了一眼，两人仍在里面写信，没有出来。它这才站起，身旁浮起淡光，片刻以后，原本小小的身影变成了她们在古墓见过的女子。

聆烨猛地站起。琉特立即挡到她身旁，手也抬了起来。

“菊音？”

女子站在桌边，望见两人的反应，原先想笑一下，最后却慢慢收住。

“是我。一直跟着你们的小狐狸，也是我。”

青江菜看向费特与十三。十三已经放下笔，脸上没有初见的惊讶。聆烨也看见了，目光在两人之间停了一阵。

“你们知道？”公主问。

“离开古墓后知道的。”十三答道，“她想留下，我没有告诉你。”

费特也点头。

“我让她答应，不再伤害同行的人。替她保密，是我们作的决定。”

聆烨听完，心里仍有些发紧。她记得梅梅将那只小狐狸抱在膝上，记得一路留给它的吃食。跟在身边这么久，自己却始终不知道是谁。

“你为什么不早些告诉我？”聆烨问菊音。

“怕你不许我留下。”菊音答得很轻，“也不知道，怎么同你说古墓里的事。”

聆烨仍站着，“古墓里还有什么事？”

菊音望过桌上的旧册，慢慢讲起殇之忆。

那时她想借聆烨最痛的记忆使她停手，深入以后，却碰到一片与眼前年岁不同的空白。再往下，是她认得的古老本源，所以才脱口叫出哀卡列斯。

“后来我毁棺，断开同杏月的联系，原先以为自己也会散掉。”菊音说道，“可最后还有一点生机，托住了没有散尽的意识。我靠它重新凝成元神，才活下来。”

“那一点，同我有关？”聆烨问。

“同你更深处的本源有关。我起初也没弄明白，后来跟着你，才渐渐认出。”

聆烨抬手按住额侧，仍想不起那时自己曾作过什么决定。菊音看见，便轻轻摇头。

“不是现在的你清醒着答应过、后来忘了。那时触到的东西，比这一世的记忆更深。”

青江菜等她说完，才问起最担心的事。

“你现在还从殿下身上取力量吗？”

“没有。我的元神已经能自己维持。”菊音望向聆烨，认真答道。

聆烨望着她，想起自己在古墓里听见的那个名字，手才慢慢从身侧松开。

“也就是说，你从那份本源里得到过力量，如今却已经能独自活下去。”

“至少我现在不需要再向你取力量。”菊音答道，“但你身上的循环，我目前没有办法解开。”

公主轻轻点头，将菊音说过的事记在心里。眼前的女子能够独自活下去，她为此松了口气，却没有再顺着自己的身世追问。

菊音退后一步，低声问：“我还能留下吗？”

聆烨看着她，没有立即作答。

“以后别再瞒着我对身边的人施术。”公主说道，“梅梅还小，她很喜欢你。”

“我知道。”菊音轻轻点头，“我想陪着她，不会伤害她。”

青江菜看了她片刻，终究将先前留给小狐狸的食物放回一边。菊音重新化回银狐，安静伏下，没有再凑过去讨好。

费特喝完杯里的茶，起身向众人告辞，独自去涵洞接姐妹。聆烨请依莎继续核对工房的记录，十三则将需要询问经手人的几处记了下来。

费特走到石台旁时，莎莉叶已经收好了两人的东西。布琪坐在榻边，喝过最后几口热粥，气色比昨日好了些。

“来接你们回去。”费特说道。

布琪向他点头，莎莉叶将水晶球放进包里，又抱起史妮司。费特接过她们的行李，等两人起身，便一同向外走去。

姐妹向笛敏特道过谢，便与费特沿原路离开。到了林间，莎莉叶抬头看见从枝叶间透下来的日光，轻轻舒了口气，又伸手牵住姐姐。

等脚步声渐渐远去，笛敏特收妥要带的东西，抬手在石台与附近几条通路间布下结界。淡光沿着岩壁缓缓连合，随后隐去，他才转身离开。可可画下的人偶构造，他仍记得。莉可未曾感受到厌夜的气息，那具身体究竟损坏到了什么程度，他要去弥赛亚亲眼看看。

三人回到营地时，青江菜先迎过来，替姐妹将床铺好，又端来温水。布琪坐下休息，莎莉叶把包放在床边，也挨着姐姐坐下来。

费特回到桌旁，告诉聆烨姐妹已经安顿好。公主轻轻点头，继续同依莎核对工房记录。

“法相这边的分送记录已经看过。”聆烨说道，“接下来要核清军中转送的经过，也得问问智相，当初定下这些安排，是准备怎样使用。”

琉特替她取出下一叠附页，翻到中间时，动作却忽然停住。

“空藏……”

聆烨抬起头。琉特已经将纸拉近，目光顺着同一行反复看了两遍。那上面不仅有空藏的名字，还有他熟悉的吐纳经路与分劲记号，后面写着的，却是罗喉。

“这也是泉房找到的？”琉特问。

依莎核过页首记载的出处。

“同旧工房的器具清单放在一起。怎么了？”

“这是老爹教过我们的。”琉特把那几笔指给她看，“可这一栏写着身体，怎么又同罗喉记在了一起？”

聆烨也认出了师父留下的习惯。她靠近看过，心里渐渐沉下去，却没有凭几行字，便替琉特说出一个结论。

“先问清楚。”公主说道。

依莎将这一页同前后的目录放在一起，请米欧核清出处。米欧看过，发现这里只摘抄了几栏，原册前后的说明并没有一并录下。

“我去问原册留在哪里。”米欧说道，“先把完整的记载找来。”

琉特没有立即应声。他盯着空藏的名字看了很久，又将后面罗喉那一行读过一遍。

“弥觉当年告诉我，是罗喉杀了老爹。”琉特低声说道，“可这里怎么又将他的身体记在罗喉下面？”

聆烨站在他身旁，也认得其中几笔调息的记号。她记起师父教拳时的身形，再想起罗喉那些曾让自己迟疑的动作，指尖慢慢收紧。

“先把原册找来，看看这里究竟是什么意思。”聆烨说道。

“我怕那里面还有老爹。”琉特抬起头，终于将一直压着的话说出，“若他还听得见我们叫他，只是没办法回答……”

聆烨的呼吸停了一下。她也曾有过同样的迟疑，眼下却无法只凭一张抄页，就向他保证仍有希望，或替他断定一切已经结束。

公主拉开身旁的椅子，请他先坐下。

“师父遇袭时发生过什么，我们会继续问。”聆烨轻声说道，“这几栏也要看完整，才能知道它同罗喉有什么关系。”

琉特坐着，过了好一阵才点头。依莎没有让他将疑问压下，只请十三另取一张纸，把需要追问的事记清。

依莎将空藏这一页另夹好，抄下所附的书名与页目，交给米欧查找。几份旧目录里还有不少沿用的旧称，也得逐一对过，才能找到相应的原册。

琉特望着聆烨，目光从她手里的记录移到脸上，眉间的忧色却没有散去。

“那你的病呢？”琉特轻声问，“守护者只替你多争取了两三个月，也得尽快找办法。”

聆烨看出他的担心，神情柔和了一些。

“我已经托青江菜去查了。”她答道，“这段时间，我还想为朝廷和百姓多做些事，也想帮帮你们。”

她低头看过空藏的名字，将纸页轻轻抚平。

“师父的事，你放不下，我也一样。趁现在还能做，总要尽力去做，免得往后想起来后悔。”

琉特低下头，过了一会儿，才轻轻点头。

“原件找到以后，我想自己看看。”琉特说道。

“我陪你。”聆烨答道。

他转头望着她，手指终于从纸边松开。聆烨替他把空藏那一页另夹好。

等众人将能先送去核对的抄件整理好，暮色已经落进院中。青江菜热了饭，见琉特还拿着纸，便先替他收开桌上的水杯，留出一块干燥的地方。

琉特坐下以后，又低头看了一眼。聆烨没有催，只陪他坐了一会儿，等他终于将那页折好，才把饭递过去。

“米欧会继续找那本原册，送到以后，我们一起看。”聆烨轻声说道。

琉特接过碗，点了点头。
