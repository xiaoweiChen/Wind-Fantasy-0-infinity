# 未完成的命令

此后两日，泉区的收停与交接仍在继续，斐南医所也送来了新回报。

玛奇朵已经能够分段转送。医者为她问妥沿途歇脚、换药的地方，才将人交给前往阳月的车队。亚岁听到消息时，正帮笙竹把几张旧记载收入包中，手停在封口，久久没有扣下。

“她醒了吗？”亚岁问。

“能说几句话了。”依莎答道，“到了以后，先让医者看过。”

亚岁点头。她想起最初那间囚室，也想起焦糖在塔上化成光的情形，心里一时说不出究竟是担心，还是终于能够问清某些事情的紧张。

车队抵达时已经入夜。依莎与米欧先到院外接人，亚岁跟在笙竹身旁，看见担架从车厢里送出来，便停下脚步，让出门口的位置。

负责护送的女子将用药交给医者，依莎向她问过姓名，才听见费特在近旁叫了一声教官。

“赛妮雅。”费特走近些，向依莎说明，“以前教过我和十三。”

十三听见声音，也走到近旁，笙竹则向护送者点头致意。赛妮雅没有在门口谈旧事，只先将路上醒过几次、喝了多少水说清，等医者接手，才回来接过依莎递的水。

“时雨请你护送？”依莎问道。

“是。他让人接到医所的消息，问我能不能走这一趟。”赛妮雅答道，“我如今替他做些护路、送人的事。”

十三站在费特身旁，听见这句，望着她停了一会儿。

“不回从前的部队了？”十三问。

“回不……不回了。”赛妮雅低声答道。

她没有再借送回伤者解释自己从前的选择。屋内有人来取空箱，她便将水放下，过去帮忙。费特看着她走开，也没有在病房外继续追问。

当夜，医者只让亚岁隔着床边看了一眼。玛奇朵还在睡，脸色比记忆中苍白得多，呼吸却已经稳了一些。亚岁在门旁站了片刻，才同笙竹一起离开，第二天用过早饭，又带着依莎过来。

玛奇朵这次醒着。

她听见脚步，慢慢转过脸，目光落到亚岁身上时，手指在被沿动了一下。

“你还在树罗。”玛奇朵的声音很哑。

“回去过，现在又来了。”亚岁在床旁坐下，“我想问你几件事。你若累了，我们就停。”

玛奇朵没有点头，也没有叫她出去。笙竹站在门旁，亚岁看过他，才重新转向床上的人。

“是谁让你去弥赛亚找我的？”

“时雨大人。”玛奇朵答道。

依莎站在床的另一侧，听到名字，目光微微一沉。她记得时雨曾在蔽天号上承认，要接回亚岁；那时却没有说，最初那场绑架也是他的安排。

“焦糖也接了这份命令？”依莎问。

“是。我们要把霜见家的继承人带回树罗。”玛奇朵说道。

亚岁原本以为，自己听完昨夜那些往事，已经能够平静些。可真正听见这句，仍想起被带离汉克、在陌生的船舱里醒来的恐惧。

“为什么不能来找我，说清楚以后再走？”她问道。

玛奇朵望着她，过了一会儿，才答：“我接到的命令，是必须带回。”

“我说过不愿意。”亚岁轻声说道。

“我知道。”

屋里安静了一阵。玛奇朵没有将被拒绝说成自己不曾听见，也没有改口称那是女孩当时不懂事。她躺在床上，声音断续，却仍将当时的想法说了出来。

“这关系到树罗往后的王位。时雨大人交下的事，我不能因为路上有人阻拦，便自己放弃。”

依莎看向她。

“所以，同伴追来，你也要继续带走她。”

“是。”玛奇朵答道。

亚岁放在膝上的手慢慢收紧。原来那些一路上的追赶、拦截，在执行命令的人眼里，都只是必须越过去的阻碍。而她惦记父亲、想回家的话，从来没有改变过这份命令。

“时雨大人说，要接我回来做皇帝？”亚岁问。

“迎回雪月的继承人。”玛奇朵说道，“至于回来以后怎样安排，由他决定。”

她说到这里，咳了起来。依莎扶她稍稍侧身，将水递近，等她喝过一口，便没有再接着问。

亚岁仍坐着，过了片刻，才低声告诉她：“我想知道父母的事，也想见笙竹哥哥。但这些，都不等于我愿意被人带走。”

玛奇朵抬眼望着她，没有回答。

医者从门口进来，看过她的气息，请几人先出去。亚岁起身让开，临走前又回头望了一眼，没有将还有许多未问完的话一口气全追下去。

到了院中，笙竹才走到她身旁。

“这份命令的具体说法，我从前没有听她讲过。”笙竹说道。

亚岁抬头看他。

“可你知道，时雨大人想接我回来。”

笙竹点头。

“我也希望能找到你。”他低声说道，“那时候收到消息，知道你还活着，我先想到的只有这一件。”

亚岁没有再问他为什么这样想。前些天，他讲起自己失去家人时的神情，她仍记得；可她也终于明白，重逢时那场跪礼背后，原来还有一件所有人都盼着她答应的事。

依莎陪两人坐到院旁，等亚岁将呼吸缓下来，才问笙竹，蔽天号为何会参与接应。

“时雨大人与久远本来就有商贸往来。”笙竹答道，“阳月需要粮食、能源和军中的用物，商团从外大地运回来。那次船回树罗时，也接了迎人的安排。”

“后来又往弥赛亚走。”依莎说道。

“还有原定的交易要做。时雨大人认为已经找到亚岁，接下来可以慢慢安排，不必在船上就决定一切。”笙竹答道，“我奉命随船照看她。至于久远同你谈了什么，我只知道你们被分开看管，没有参加那场会面。”

依莎听完，没有把所有人的目的混成一件事。玛奇朵要将人带回，时雨要迎立继承人，久远却在这趟航程中扣住自己，追问另一样东西。几方借同一艘船办事，未必彼此知道全部安排。

“现在他还要你做什么？”依莎问。

“陪着亚岁，将她的身世说清。”笙竹答道，“以后去日冕，同旧族的人见面。”

“我还没有答应去。”亚岁说道。

“我知道。”笙竹看向她，“我会照你的话转告。”

这句话同船上已经有了些不同。他没有先跪下，也没有再叫她殿下，而是等她说完，才应下自己接下来要做的事。

午后，依莎请聆烨过来。亚岁同意让公主知道自己问到的经过，便亲自将那本族谱和玛奇朵的回答讲给她听。笙竹坐在近旁，补过自己经手的部分，没有替时雨猜测未说出口的话。

聆烨听完，目光在霜见那一页停了很久。

她认得古礼里的那一支，也知道玄冬之后原本应当迎谁。她当年迎立星回，是因为雪月王家遭难、继承人失踪，国中又不能没有人理政。如今亚岁活着回来，那些被暂时放下的争议，也一同回来了。

“我想先问你本人。”聆烨抬起头，“你愿意留下，参与这件事吗？”

“我还想回弥赛亚。”亚岁答道，“这里有需要帮忙的，我愿意做，可我没有答应当皇帝。”

公主轻轻点头，将手从族谱边收回。

“我会同陛下说明。叔父那边，也不能把你已经回来，当作你已经同意。”

笙竹望着公主，慢慢应下。他原本一直在想，该怎样使亚岁理解那些人寄在她身上的期望，如今却不得不先学着，将她真正说过的话带回去。

傍晚，他给日冕写去简短回报，说明亚岁平安，也将不愿继位、仍想回弥赛亚的意思写清。信封合上以前，笙竹又读了一遍，才交给原先负责往来的送信人。
