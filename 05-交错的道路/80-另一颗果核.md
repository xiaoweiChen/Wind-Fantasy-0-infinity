# 另一颗果核

第二天，布琪起得比平日迟。

莎莉叶坐在床边穿好鞋，叫了两声，才见姐姐撑着枕头坐起来。布琪说昨夜没睡好，等妹妹先去洗漱，又独自坐了一会儿，才慢慢站稳。

早饭时，依莎问她要不要改日再去涵洞。布琪望向妹妹，见莎莉叶已经将水晶球收好，便轻轻摇头。

“走得慢一点就好。我也想见见他。”

费特领路，带依莎与两姐妹沿熟路下行。入口的结界已经放开，石台附近也少了许多飞舞的绿光。

笛敏特站在那边等候。费特将公主托带的抄页交给他，说明是昨日从泉房带回的旧例与用物记录。

“机器由智相安排，法相负责分送、装用。”费特说道，“还有一批曾经武相转手，又送到阳月，后来才回到采办处。殿下还在核中间的去处，想先请你看看，旧例里记着的魔力耗损，是怎么回事。”

笛敏特接过纸，按费特指出的页目夹好。

“我先看看这些旧例。”他说道，随后望向走在后面的布琪。她的步子比其他人慢，脸上也没有多少血色。

他将抄页放在石台上，领几人来到旁边安静的石室。

“先坐下吧。”笛敏特说道。

布琪将史妮司递还妹妹，刚要放开扶着石壁的手，膝头却忽然一软。莎莉叶赶紧抱住她的手臂，依莎也从另一侧扶住，将人送到铺着毯子的矮榻上。

“姐姐？”

莎莉叶叫得很急。布琪还想答话，手却冷得握不住妹妹，只得先靠在枕边，缓过一口气。

笛敏特已经来到榻旁，托住她的手，留意掌中尚未散开的微光。

“昨天用了多少魔法？”他问。

“在工房外转送病人的时候，用过一点。”布琪低声答道，“没有很久。”

“她夜里也没歇好。”莎莉叶紧跟着说，“早上就没有精神。是不是昨天太累了？”

笛敏特轻轻摇头，示意她将水晶球取出来。

“球里存着的力量，能先帮她补上。你已经会收进去，这次我教你怎样取出来。”

莎莉叶立即打开小包。球体被她捧到姐姐手边，里面的绿光安静浮动，同她第一次失控时的灼热完全不同。

“要怎么做？”妹妹问。

笛敏特将手指停在球面的银纹旁，让她看清其中一处连接。

“先放开这里，只引出一点。别急。”

莎莉叶依着他指的位置试。开头光只在球里转，她不由得又向姐姐望去。布琪正看着她，见她紧张，便勉强笑了一下。

“我在这里。慢慢来。”布琪轻声说。

妹妹低头重新试过。这一次，一缕细光终于从银纹间流出。笛敏特托稳布琪的手，将那缕力量引入掌心，又叫莎莉叶收住，不必一次放得太多。

石室里安静下来。莎莉叶两手捧球，视线一直跟着那道光。过了好一阵，布琪原先绷紧的指节才慢慢放松，指尖也不再那样冰冷。

“还要吗？”莎莉叶急着问。

“先停。”笛敏特答道，“已经够她缓过来了。”

他让妹妹重新合起银纹。球内的亮色淡了一些，却没有消失。莎莉叶小心地将它放在姐姐身旁，直到布琪能自己拿起水杯，才稍稍松开攥着衣摆的手。

依莎见她恢复了一点血色，也终于放心，将毯子展开，盖在两人膝上。

“今天先在这里休息吧。”依莎说道。

布琪点头，向她道谢。费特随依莎去外面安排行李与饭食，石室里便只剩姐妹俩与笛敏特。

莎莉叶靠着姐姐坐了很久，不时伸手摸摸她的手指。确认还是暖的，才将水杯放回桌上。

“刚才你的手那么冷，我很害怕。”莎莉叶低声说道。

布琪握住妹妹的手，放到自己掌中。莎莉叶低头看着，指尖慢慢松开，目光却仍留在姐姐脸上。

昨日母亲的旧事已经说清，方才那阵冰冷却仍使她想起守在病床边的日子。眼下姐姐能够握着自己、轻声回答，她才一点点安心下来。

“以后不舒服，要先告诉我。”莎莉叶轻声说道。

“嗯。”布琪替她理好额前的头发，“刚才吓着你了。”

“我以为……”妹妹低下头，没有说完。

布琪明白她想起了谁，将她轻轻搂近。莎莉叶没有像往常那样坐开，只抱着史妮司，靠在姐姐身边。昨夜为了母亲的旧事，她也醒过几回，如今等到姐姐终于好转，眼皮才渐渐沉下去。

等妹妹睡稳，布琪才慢慢将她的手放进毯下。水晶球搁在枕边，绿光映着两人的衣袖。布琪看了许久，抬眼望向仍在近旁的笛敏特。

“你那天就看出来了。”布琪低声说。

笛敏特在榻边坐下。

“那颗核没有长全。”他答道，“她的力量很强，你这边却补得慢。昨天又用了魔法，夜里没能休息，才撑不住的，对吧。”

布琪低头看着自己的手。那是孩子的手，比记忆里摘下果实时的那双小了许多。她轻轻合拢手掌，方才补进来的力量还在慢慢散开。

“我打开果实的时候，确实看见了两颗核。”布琪说道，“可其中一颗，已经没有生命了。”

笛敏特没有打断。布琪的声音很轻，说到这里，又停下来听了听妹妹的呼吸，才继续往下说。

“另一颗很强。应该是还没离开果实，就把旁边那颗的生命力吸走了。我起初不明白，等了很久，以为只是醒得迟。”

她看向莎莉叶。妹妹睡着时，脸颊仍贴着玩具的一角，手指像怕它掉下去，始终扣得很紧。

“可她什么都不知道。醒过来以后，只会抓着我的手。”

布琪伸出指尖，轻轻碰了碰那只露在毯外的小手，神情渐渐柔和下来。

“月之魔女的果核，会从成年魔女身上吸收力量，长成自己的身体。我知道陪着她，魔力会衰减得更快。往后靠月光，也不一定补得回来。”

“所以，你想到了另一颗核。”笛敏特说道。

布琪点头。

“它们之间还留着联系。我想着，若能让那副身体也活过来，也许等原来的身体老去以后，我还可以陪着她。”

她的目光落到膝上的毯子，手指沿柔软的边缘慢慢抚过。

“我分出了一部分灵魂，放进那颗已经死去的核里。过了些日子，它终于有了回应。后来睁开眼，看见的是我原来的身体，还有睡在旁边的莎莉叶。”

“你们的记忆一直相通？”笛敏特轻声问。

“相通。原来的身体知道这边在做什么，这边也知道她遇见过谁。”布琪答道，“莎莉叶长大一点，便叫这副身体姐姐。”

说到这里，她唇边浮起一丝很浅的笑。

“她学会一点新魔法，先跑去让母亲看，再来拉我，说姐姐也要看。我就坐下，让她再施一次。明明已经看过了，可她会很高兴。”

笛敏特看过姐妹相近的面容，没有替她把那些日子说成一场虚假的扮演。

在那个小小的家里，母亲确实做过饭、替孩子梳过头，姐姐也确实陪妹妹长大。车里那次夜谈，布琪讲过的生活都是真的，只是同伴不知道，母亲与姐姐之间还连着同一份记忆。

“分开灵魂以后，原身的魔力少了很多。”布琪慢慢收起笑意，“从前能随手做的事，后来得等一等，才有力量再做。”

她记得自己从前在树根深处施术，绿光能够一层层越过石壁，直到天将亮，掌心仍留着余温。石后的提灯晃过一次，又安静下来，后来再想起，仿佛已经隔了很远。

如今她只抬起这副年幼身体的手，看了一会儿，便重新放回妹妹近旁。

山里的食物减少，她便带着两个孩子去了首都。她记得路上遇见过的人，也记得自己为什么停下来帮忙。那时只觉得回去以后还能慢慢恢复，没有想到进城后，会被兵士围住。

“原来的身体被带走，我这边就知道了。”布琪说道，“可这副身体太弱，莎莉叶又一直在问，妈妈为什么还不回来。”

她垂下眼，过了片刻才接下去。

“我不能再让她一个人等。我只好陪着她，等别人送来消息。”

笛敏特看向放在枕边的史妮司。布琪的手也停在玩具近旁，却没有将藏在里面的纸取出来。

“工房里的人，要我恢复树根。但我的那具身躯已经做不到了，他们还是逼着我反复施术，原本就不多的魔力，也耗得越来越少。”布琪低声说道，“后来接触到同世界树相连的根，补回了一点魔力，我才有机会逃出去。”

笛敏特安静听着。布琪将妹妹露在外面的手轻轻放回毯下，指尖停了片刻。她记得，这只手也曾紧紧握着病床上那具身体的手，怎么哄都不肯松开。

“后来，莎莉叶好不容易找到我，就一直守在床边。”布琪的声音有些发颤，“她只是怕，一松开手，妈妈又会被带走。”

石室里安静了许久。

布琪仍记得原身躺在床上时，看见妹妹哭得抬不起头，自己想摸摸她的脸，却连手也抬不起来。另一副年幼的身体就坐在床旁，一边握着妹妹，一边承受同样清楚的衰竭与疼痛。

“她不知道，果核还在吸收母亲最后的力量。”布琪说道，“原身剩得太少，后来就再也没有醒过来。”

笛敏特没有说话。布琪按住有些发抖的手，停了很久，才缓缓摇头。

“我从来没有怪她。她没有做错什么。”

墓园里，莎莉叶向母亲解释为什么迟迟没有来，布琪告诉她，妈妈不会怪她。那句话也是她此刻想说的。妹妹不该因为自己曾被抱过、照顾过，就为活下来觉得有罪。

“所以，墓里的身体是真的。”笛敏特轻声说道。

“是真的。”布琪点头，“那副身体再也不能回家了。她熟悉的声音、模样，都没有了。我只能用现在的样子抱着她，让她叫姐姐。”

她低头替妹妹掖好毯角。

“留下的影像和声音，我放进了玩具。她想妈妈的时候，可以再看看。可里面不会多说一句新话，她问过以后，还是会回头来找我。”

莎莉叶在梦里动了一下，手从毯边探出来。布琪立即握住，等她重新睡稳，才看向笛敏特。

“先不要告诉她这些。”布琪说道。

“我明白。”笛敏特答道。

他将水晶球挪到两人都能看见的位置，指尖轻轻点过球面。

“她的核吸收过另一颗的力量，在这里又被孢子激发，才会聚得太快。你这颗核不完整，世界树给你补充时，反而是在填原先不足的地方。”

布琪想起初入涵洞时，自己只觉得疲倦在减轻，妹妹的手却越来越热。那时她忙着扶住莎莉叶，没有想到，同一个地方对两人的影响会有这样大的差别。

“球里存下的力量与你们同源，可以取用。”笛敏特说道，“但一次取多少，要慢慢试。”

他又示范了一次开合银纹。布琪看得认真，用空着的手试过，确认能够重新合住，才将球放回妹妹手边。

“等她醒来，我陪她练。”布琪轻声说。

“好。”

笛敏特起身，将水杯放到布琪够得到的地方。

“我就在外面的石台。今天不用再施术，好好歇一歇。”

布琪点头，看着他放轻脚步离开。石室里只剩下姐妹俩，莎莉叶的呼吸轻而平稳，手心也一直是暖的。

过了一会儿，妹妹含糊叫了一声姐姐。

“在呢。”布琪俯下身，轻声答道。

她没有松开那只手，陪妹妹又坐了很久。
