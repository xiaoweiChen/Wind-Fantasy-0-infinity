# 林间的道别

聆烨收好料棚的抄件，请熟悉村路的人替她同水工约好，次日再去旧沟处理装置。至于林后那座旧库，众人没有再往近处走。

当晚，费特与魔女姐妹带着断箍和记下的纹样，再次来到茧之座，请笛敏特辨认。笛敏特先散去姐妹周围的孢子，再将图同断箍内侧的刻痕对过，指出仍在牵引根系的那一道符纹。

“先把送进箍里的力量引开，等这道纹暗下来，再松外扣。”笛敏特向姐妹说明，“只能先停这一处，其他连接还得继续查。”

布琪同妹妹记下方法，又将几处不明白的地方问清。费特收好图，三人回到地面，把处理的办法告诉聆烨，约好次日由水工看着水路，再尝试取下装置。

第二天清早，众人回到旧沟。浅沟里的水仍在流，昨日打湿的地面已经退下去一小片，原先被牵偏的那束根却还贴着石壁，箍内的微光也没有消失。

水工先查看浅沟，搬开出口几块容易挡水的碎石，才请姐妹动手。布琪照着笛敏特指过的位置，辨出送入符纹的力量，莎莉叶随后伸手，将它缓缓引向箍外。内侧的光先晃了一下，又渐渐暗下去，贴在金属上的细根也随之松开。

布琪蹲下察看，确认外扣已经松动，才回头向费特说道：“可以取了。”

费特用工具挑开松动的外扣，艾因接住滑下来的铁件，两人将它移到岸上。水工守着沟口，看见水量突然增大，立即叫琉特先将近旁一块垫石挪开，让多出来的水沿浅沟分走。

泥水冲过沟底，卷起一阵碎叶。莉可站在较高处，向艾因指明仍卡在出口的倒枝。十三从另一侧伸手，将它拖出水面，旁边那股不断打转的水才顺着旧槽流了下去。

众人没有急着收东西。水工往下走过两户，又折回来，确认木槽接得住、靠近墓地的那段也没有被新水冲开，才向公主点头。

“水已经顺着旧沟流到下游，那几户人家可以重新取水了。”水工说道，“我明早再来量一次水量。要是又断了水，或是水涨得太多，我就托人给殿下送信。”

聆烨把可以递信的地方告诉他，请他将实际量到的情况写下。艾因擦去取下的金属箍上的泥，交给公主。她将它同料棚的抄件放好，又看了一眼重新通水的旧沟。

“这里已经恢复用水，后面请水工继续照看。我们这一趟先查到这里。”聆烨向同伴说道，“接下来我回朝见陛下，把改动根系的事报上去，请她派人核对器具领用和运输的原簿，查清是谁下令、为什么把水引去旧库。”

琉特应下，将水工补画的沟图也收好。眼前的断水已经处理，牵涉朝廷各方的命令与去向，却需要更多人手继续追查。

艾因同莉可对视一眼，见她轻轻点头，才向公主说道：“那我们也准备回弥赛亚。”

“好。”聆烨答应，“这几日多亏你们帮忙。”

回到空屋时，青江菜正在清点余粮，准备添买路上用的食物。梅梅坐在门边，见十三鞋上沾着泥，先将擦脚的布推过去，才问今天是不是要离开这里。

“还不走，路上要用的东西得先备好。”十三在她面前蹲下，“殿下要回王都，向陛下报告水沟的事。我同费特陪艾因他们回弥赛亚，到了以后再托人送消息来。”

梅梅看过他，又向屋里望去。聆烨正在同莉可说话，青江菜也还留在桌旁。她伸手碰了碰小狐狸的背，过了一会儿，才问十三会不会连告别也不说就走。

“会先同你说。”十三答道。

梅梅低头理好擦脚布，让出门口的位置，十三才起身进屋。

桌边，布琪摊开了通往幻之湖的地图，同妹妹商量原定返回日晷的路线。聆烨听见，便在她们身旁坐下。

“法相的人还在找你们，继续留在树罗，恐怕又会被他们带走。”公主说道，“不如先同艾因、费特他们去弥赛亚住一阵。等我回朝查清寻人的命令和泉区试术的事，再商量回程。”

布琪看向妹妹。莎莉叶仍记得昨日料棚外询问她们去向的声音，指尖在地图上停了一会儿，才抬起头。

“去弥赛亚的话，能不能也去找找燧火？”莎莉叶轻声问，“我想再见见他。”

“一起走吧。”十三答道，“弥赛亚的公会一定有燧火的消息，到了我们陪你们去问。”

布琪应下，向几人道谢。莎莉叶眼里也有了亮色，随后将地图往桌子中间挪了挪，看向连接树罗与外面的那段路。

“现在出去，还得从幻之湖绕吗？”妹妹问道。

“照我们问到的航路，是这样。”费特答道，“不过，离开时的航季已经过了。”

几人商量过，决定再向笛敏特请教。

当日下午，聆烨与琉特陪艾因几人下到茧之座。艾因先说明他们想离开树罗，却还没有找到合适的出境办法。笛敏特听过，转头看向两姐妹。

“借助我送你的水晶球，你们能让树罗外围的幻象暂时减弱，显出被遮住的航路。”笛敏特向莎莉叶说道。

莎莉叶抬头看他。

“可我们以前没学过这种魔法。”妹妹说道。

“我教你们。”笛敏特笑了笑，“先在这里练习，试着让眼前的幻象变淡，能看清路就好。”

莎莉叶依言取出水晶球。笛敏特将操控水晶球、用它驱散幻象的方法教给姐妹，末了随口补了一句：“这法术反过来用，也能增强幻象。”

笛敏特带姐妹走到茧之座内一处较空旷的石台，先挥手散去附近的孢子，再引动浅水上的倒影。映在洞壁上的光渐渐错开，原本低矮的石坡，从某个角度看，竟像向下陷去的深沟。艾因看见，脚步不由得慢了一些。莉可轻轻碰过他的手腕，陪他站在外侧。

笛敏特借水晶球示范了一遍。球面浮起一层柔光，照到前方的石坡，重叠的影像便渐渐淡去，露出原本平缓的坡面。他将球交还给莎莉叶，便走回石台另一侧，留下姐妹自行练习。

莎莉叶捧稳水晶球，照着刚学的法术尝试催动。起初球面只有一小点光，刚照清半块石头，就忽然熄了。她皱起眉，想立即再来，布琪却先扶住她的手。

“慢一点，照刚才的顺序再试。”姐姐轻声提醒。

莎莉叶缓了一会儿，重新念起咒语。这次球上的光亮得更久，前方的重影也退开了一些。布琪站在近旁，帮她留意哪一次停顿之后光开始减弱。姐妹反复试过几次，才终于让十三看清石坡底下真正散落的几块碎石。

“这下能认路了。”十三说道。

他先走过那一段，又折回给姐妹指出，自己方才站在哪里看得最清楚。琉特在另一侧等着，见重影重新合起，才明白这条路不能只让开头的人看见，还得照应后面的人通过。

“我来断后。”琉特说道。

莎莉叶听见，侧头看了他一眼，再转回身，捧着水晶球慢慢调整方向。球光沿石路移过去，照出后面的人仍需经过的地方。

次日，姐妹又回到石台边，照着记下的方法自行练习。妹妹掌握了催动球光的办法，姐姐便接过水晶球，试着让光稳定下来，再沿着石路一点点移向远处。两人轮流尝试，将各自摸索出的诀窍说给对方听。

到午后，莎莉叶已经能让球光照过一段窄路，缓缓驱散挡在面前的重影。她又试着走了几步，光没有像最初那样立刻熄灭，唇边终于扬起笑意。

“姐姐，你看。”莎莉叶轻声叫她。

布琪走到妹妹身旁，顺着被照清的石路望过去，也笑着点了点头。

离开茧之座以前，莎莉叶将水晶球小心收进包里，扣好了包口。

艾因与莉可随后走到他面前，向他郑重道谢。笛敏特仍站在石台旁，含笑看着两人，没有随他们往外走。

“我们先走了。”莉可轻声说。

“路上顺利。”笛敏特答道。

莉可望了他片刻，轻轻点头，才同艾因一道转身。众人向笛敏特道别后，沿熟悉的石路回到地面。

临行那天，聆烨同琉特先将地图铺在车旁。公主的车回首都，艾因等人则要沿另一条路去外缘的旧渡口。那里有短途运货的船，能够先送他们到接近幻象的水道，再从外侧另寻返乡的交通。

青江菜替他们问过船价，说明船主原本只走外围几处落脚地，不熟悉弥赛亚航线。船主愿意载这一段，但要先在近岸试过能否辨清去路，才往里面行。

“到了外面，得自己再找船。”青江菜向费特说道，“我把接驳处标在地图上，后面问路时也能用得上。”

费特接过地图，认真向她道谢。

莉可走到聆烨面前，向她道谢。

“这些日子，劳您费心了。”莉可轻声说道。

“你们也帮了我许多。”聆烨微笑道，“一路平安。”

费特收好地图，走到琉特面前，两人握了一下手。

十三最后来到梅梅身旁。孩子将小狐狸抱得很稳，听见他叫自己，才抬起眼。

“我要走了。”十三放轻声音，“后面记得好好吃饭呀。”

梅梅没有回答这句，停了一会儿，才说：“到了以后，记得给我们来信。”

十三点头答应。梅梅朝他摆了一下手，随后转身爬回车内。

聆烨的蒸汽车先从岔口转开。琉特回头时，看见六人仍站在路旁向他们挥手，布琪替妹妹压住被风掀起的外衣，费特则已经展开了接下来要用的地图。

两天以后，艾因等人才到达旧渡口。船主先带他们在浅水处试航。起初，岸边的同一块白石总在两侧轮流出现，莎莉叶便托起水晶球，用新学的法术催动球光。光芒照向船前，重叠的岸影渐渐淡去，真正的礁石与水道才显现出来。

费特站在船头，将礁石的位置报给掌舵的人。十三留在姐妹身旁，见妹妹捧球久了，便问需不需要靠岸歇一会儿。莎莉叶应下，将水晶球交给布琪接着操控，又让船停在能看清实岸的地方。

接下来几段，他们也是这样慢慢通过。有时前方又出现从来时见过的岛影，船主便不急着转舵，等姐妹借水晶球驱散重影，看清真正的水道，再继续往前。

最后一片相叠的岸线从眼前退开时，风先变了。水面的亮色不再反复移向同一处，远方落脚岛上的屋顶，也终于随着船行慢慢靠近。

艾因回头望去。树罗仍在幻象后面，方才经过的路很快又变得模糊。他下意识向莉可伸手，女孩却已经站到身旁，稳稳握住了他。

“出来了。”莉可轻声说道。

“嗯。”艾因答道，望着她有些疲倦、却仍清醒的脸，慢慢笑了。

靠岸以后，姐妹先在船棚里歇息。费特带着标好接驳处的地图，同十三去问换乘的船。艾因替莉可取来温水，陪她坐在棚下等候。

想起仍在弥赛亚等消息的梅鲁，艾因打算等费特回来，同他商量托人报个平安。归期尚未确定，那些年没能说清的事，等回家以后，再亲口慢慢讲。
