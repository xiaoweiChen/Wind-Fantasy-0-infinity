# 钟声与契约

先抵达斐南的，是依莎一行。

离开利凡提以后，他们沿地图上的道路继续赶路，途中补过水，也停下来休息。直到城中的巨钟远远出现在视野里，米欧才将图稍稍收起，告诉亚岁，前面就是要去补给的地方。

依莎请亚岁在城外停好车，先核过还缺的物品，再带众人进城。新街与房舍排得齐整，来往的人却不像利凡提准备选拔时那样热闹。她沿路看过几家铺子，还没问清该往哪里去，莎莉叶便在后面慢了脚步。

“燧火，帮我一下。”少女伸手拉他，“走了这么久，累了。”

燧火回过头，依莎已经先看向不远处的摊子。

“前面有个卖糖果的摊子。我们去那边坐坐，买点东西，歇够了再走。”

莎莉叶还想说什么，目光先被摊上的东西吸引，只好跟着姐姐往前。布琪听见燧火松了口气，忍不住轻轻笑了一声，依莎却已经在摊前停住。

她看见了一只熟悉的包装袋。

“这个……是弥赛亚波奇店里的？”

摊主见她问得认真，便将东西拿近些。依莎看过上面的字样，又递给燧火。阿克雅以前带到公会分过这样的饼干，他还记得那只袋子。

“确实见过。”燧火抬起头，声音里已有些掩不住的急切，“这些能运进来，是有船同外大地往来？”

“商会运来的货。”摊主答道，“具体怎样走，要问翼手龙商会。这里管事的是巴尔。”

依莎与燧火对望一眼。落到树罗以后，他们一直想找到回去的办法，至少也得先同弥赛亚联络，让汉克知道大家还活着。如今熟悉的货就在眼前，总比一路只向人打听传闻更像能接上的线索。

“那能不能借商会传个消息？”依莎问，“我们带着通讯器，可来到这里，一直没能联络上家里。”

摊主听完，提起巴尔正准备在巨钟塔安装沃坦之石。燧火几乎立即想到了布琳希尔通讯器，回头问依莎，若装置能用，他们是不是就能试着联系汉克。

“至少得去问问。”依莎应道，又向摊主说，“能让两边互通消息，总是件好事。”

摊主的脸色却沉了下来。

“好事？你们也是替巴尔来说这些的？”

依莎一怔，刚要解释，旁边已有几个人围过来。有人听见沃坦之石，又看见他们是外地面孔，便认定商会又找了人来劝居民让步。

“我们只是来问路和通讯。”依莎将饼干放回摊上，“还没有见过巴尔。”

“那就别一开口便替他说话！”有人扬声道，“巨钟保卫团不会再上当。你们若是商会请来的，去别处说！”

亚岁赶紧将姐妹往近旁拉了一点，米欧也留意着后面的通路。燧火想再解释，几个人却各说各的，谁也没等他把来历讲完。

人群外这时传来迪诺的声音。

“他们同商会没有关系，是我的朋友。”

鬼罹也随他走近。迪诺向摊主说明，几人刚从利凡提来，只想补给和找回家的办法，请大家别把没弄清楚的事先算到外地人头上。

有人认得他，提起艾杰尔，迪诺点头，说明自己能替这几人的身份作证。居民见他们同保卫团首领的熟人站在一处，态度才渐渐缓下来，各自散开。

依莎等人群退去，才真正有机会问：“为什么一提装置，大家会这样生气？你们同艾杰尔又是什么关系？”

“我们是朋友。”迪诺先答，“其他的，换个地方慢慢说吧。站在摊前，只会又让人围过来。”

依莎买好答应给姐妹的糖果，才随两人离开主街。迪诺领众人进了稍远的一家茶铺，等都坐下，再请依莎说明来意。听清他们确实没有先接商会的工作，他才从随身物件里拿出几张记录，放到桌上。

“城里有些人愿意把经历讲给我们听，我记下了这些。”他将其中几项指给她看，“先从粮食说起，不只是一个钟要不要留下。”

泉水的奇迹消失以前，巴尔便以高出市价三成的价格，大量收购粮食。卖粮的人得到更多钱，当时多半觉得是一笔好交易；等后来各地歉收、别处也调不出足够粮食，仍能买到的存粮，却已经集中在商会手里。

“然后，他再以市价四倍左右的价格卖回来。”迪诺说道。

米欧低头看过那几项数字，慢慢接道：“卖出去拿到的钱，已经买不回原来那么多粮。”

“而且，不是换一家店就能便宜些。”迪诺点头，“外面也在缺，自己地里又种不出来。为了吃下去，只好再借钱。”

依莎听到这里，先问那些粮，当初是否真由居民自己答应卖出。

迪诺说是，也提醒她，没人能凭那时的收购价，便知道后来泉水会失效。

“我明白他们没有料到。”依莎将记录拉近，“可单说当初那笔交易，巴尔付了钱，卖的人也收下了。不能只因为后来价钱变了，就说从前的约定不算。”

“所以，我才让你把后面也听完。”迪诺没有生气，“现在的人，不只是觉得卖便宜了。他们已经没有粮，也快没有别的东西可以拿去还债。”

亚岁拿出纸，将听到的先后记下。她在晶体屋也见过买卖与赊欠，可一份账只说这一回卖了多少、赚了多少，连起来却能使人连下一顿吃什么也作不了主，她还是第一次这样看清。

“那钟塔呢？”依莎问，“怎么也会卖给巴尔？”

“债越来越多，城里也得想办法。”迪诺答道，“钟塔已经成了商会买下的财产。如今要在那上面安装装置，就要拆除原来的双子巨钟，保卫团不肯让步。”

他又说明，守塔的许多人都是本地居民，有人要留下钟，也有人不肯再看着城中的东西，一件件变成巴尔继续索取的凭据。

依莎看了片刻记录，还是摇头。

“他趁缺粮这样赚钱，我也不赞同。可签过契约的人，仍得对自己的决定负责。若觉得吃亏便拿起武器，占着卖掉的东西不交，往后的约定还怎么做？”

“真有余地选的人，当然该先想清楚。”迪诺看着她，“可等人已经饿着，面前只剩下借债和挨饿，你从后面回看，觉得每一步都能停，当时的人却未必有那份从容。”

依莎一时没接上。她不愿随口答应所有欠债都能不算，也无法将眼前这些经历，简单当成谁签字前不够小心。最后只把那几张记录还到迪诺手边，说明自己仍想见见巴尔。

“不过通讯的事，还是得去问他。”

迪诺没有拦，只请她见过以后，再自己判断。

当天回车旁，依莎将要补的物品同伙伴核过，留到翌晨，才与燧火一道去拜访商会。亚岁等人留下整理，凯蒂也趁有空，重新清点自己的货物。

两人照问来的地址走进主街，到了门前，燧火先看过守卫，又望向依莎。这里并不像寻常店铺，进出的人也要先由门边通报。

商会的临时办事处，竟设在城主官邸。

巴尔很快请两人入内。他已经听过弥赛亚冒险团的名字，说起蜃龙村与利凡提的事，语气亲切得像早已等候多时。

“几位既有这样的本事，正好也能替斐南解一件难事。”

依莎没有立即接他的称赞，先说明来问商路和通讯。巴尔听完，顺势将话引到沃坦之石。

“只要装置顺利架起来，同外大地联系，也就有办法。眼下拦着工程的，正是巨钟保卫团。”

“你想委托我们驱逐他们？”依莎问。

“让商会能使用自己合法买到的地方，完成安装。”巴尔说完，报出酬劳，“五百万树罗币。”

燧火的目光微微一动。这个数同他们先前辛苦做完的零散工作，差得实在太远。依莎却没有先问怎样领钱，而是看向巴尔桌上的钟塔位置。

“能不能留下钟，另找地方装？一定要走到双方拿兵器相对的地步？”

巴尔解释，双子巨钟会同首都主钟共鸣，干扰沃坦之石，使讯号短暂失效，时间久了，还可能损坏装置。

“选中钟塔，也是因为那里够高、够开阔。”他继续说道，“这些事已经在准备，不能一直因他们不肯退，就拖下去。”

“所以，你认为没有再商量的必要？”

“至少，他们该先离开商会的财产。”巴尔答道，“保卫团的首领艾杰尔，偏偏又是城主的独子。父亲同商会交涉，儿子在塔里不退，你们觉得，这对已经付过钱的人公平吗？”

依莎记着这番话，也记着昨日城民的神情，没有立即附和他对父子二人的判断。巴尔见她仍在思量，又提醒，只要工程完成，他们很快便能给弥赛亚传讯，不必继续让家里担心。

燧火看向会长，等她回答。

依莎低头想了片刻，最终还是摇头。

“这份工作，我们不接。”

巴尔像没料到如此，连笑容也稍稍停住。

“是酬劳不合适？”

“与金额无关。”依莎说道，“这里牵涉居民、守军和城主，不能当作寻常的驱逐委托。还得再问问情况。”

巴尔又劝了几句，她没有改口。临走时，对方转而提议送一些补给，算商会与公会以往往来的一点心意，依莎仍没有收。

“以前的工作，我们按约做，商会也按约付钱。没有谁额外照顾谁，这次就不必再送了。”

两人走出官邸，燧火回头看了一眼，才问她，通讯的事是不是也只能先放着。

“再找办法。”依莎答道，“至少，不能先领一份人情，回头再说自己同这件事没有关系。”

可回到车旁，他们便看见已经堆好的物资。凯蒂正请亚岁替她挪开一点位置，见会长回来，还高兴地说，这回买得很合算。

“商会派来的人说，刚好有一批货能低价出售。品质也好，够我们路上用，我便先垫钱买了。”

依莎在物资前停住，许久没有出声。凯蒂看过她的神情，脸上的高兴渐渐收了。

“不能买吗？我以为，正好能替大家省一些。”

“你不知道我刚拒过他们送东西。”依莎没有责怪她，先问清价钱和交货经过，才低头看向那些包裹，“不是货不好，是我不能收了商会特意让出的便宜，又在委托上说自己完全没有欠情。”

她让凯蒂别为垫款担心，自己会补回，但这批东西仍要退。姑娘点了点头，正要重新归拢，迪诺与鬼罹便从路边走近。

“见过巴尔了？”迪诺先打招呼，“昨天说要去，过来看看，事情问得怎样。”

依莎说明拒绝委托和补给的经过，又将眼前这批低价买来的东西指给他看。迪诺听完，想了一会儿，提出不必再来回搬回商会。

“照凯蒂付的钱，卖给我们吧。你们没有留着用，也不用她再为这笔钱发愁。城外有人需要这些食物。”

“城外哪里？送给谁？”依莎问。

“卧薪村。原先住在斐南城里的那些人。”

依莎又看过物资，同凯蒂核清垫付数目。迪诺将钱直接交给姑娘，凯蒂数清收好，这笔本钱便算补回，公会也不必再重复赔付。鬼罹帮着点过东西，准备送去村里，迪诺却请众人一同去看。

“有些事，坐在城里听完，还是同亲眼见到不同。”

他们离开新街，沿城边的路往外走。斐南整齐的房舍还在近旁，卧薪村低矮的屋顶却已出现在前面。等真正走进去，亚岁才发现，那些临时搭起的地方，比远看时更难挡住风雨。

没有供日常使用的荧石发电机，取来的水也只能经旧沉淀装置处理。有人听说送来食物，便放下手里的活走近，看清数量，又先问够不够分给其他家。

村边一个负责警戒的人迎过来，迪诺叫住他，介绍弥赛亚来的朋友。那人报了名字，叫克雷米，先谢过带来的物资，才帮忙安排放置。

依莎还不知道，这个正替村民搬东西的人，曾经也是聆烨的随从。

等众人安顿好，依莎才问：“他们原来住在城里，为什么会全搬到这里？是自己愿意出来？”

迪诺拿出另一份居民旧屋的记录，放到她面前。

“先是粮债，还不上，便把房子卖给商会抵债。然后再把土地租出去，收些租金。商会拆旧屋、建新城，叫他们在修好以前，先来这里住。”

依莎看过两处不同的约定，又问：“房子卖了，土地仍是他们的？”

“地没有卖，是另外出租。”迪诺答道。

“那租约解除，收回自己的地以后，为什么不能搬回去？”

“因为地上的新屋，归商会所有。”迪诺将后面的条款指给她看，“想住进去，还得另外买。抵完粮债剩下的那点钱，加上租金，又得支应这段日子的吃用，哪里够买新房？”

亚岁听到这里，才慢慢看向近旁那些崭新的屋顶。

“所以，他们拿回地，也拿不回原来住得起的家。”

“要住，就另付钱。”迪诺说，“买不起，也可以租。巴尔后来正是这样告诉他们的。”

依莎没有立即说话。单独看每一份纸，确实都写过卖什么、租什么，可落到一个家庭身上，先卖屋换粮、再离家等重建，到最后连回去住，也成了必须重新借钱的事。

克雷米这时又提起镰刃螳螂。入秋以后，那种魔兽开始在附近捕食，村子恰好建在猎场，人们出门做事，到了时候便得留意警钟。

“城里至少有房子，也能躲。”他看向新城的方向，“可付不起买屋的钱，只能再租。再加上粮食，一家人要填的债，就越来越多。”

“后来有人离开树罗？”依莎问。

迪诺点头，说起那些被叫作奉献契约的约定：欠债者被送到外大地，替翼手龙商会工作，直到把债还清。

“去了以后，就没有再给家里传消息。”他低声说，“等着的人一直在问，可总没有能让他们放心的答复。”

依莎想起利凡提那夜，脸上的神情渐渐变了。

“你在查这些失踪的人？”

“在查，也怀疑同魔魇有关。”迪诺答道，“可目前还没有查清，不能只因人没消息，便说已经知道他们在哪里、出了什么事。”

他没有拿猜测当成结案的答案。依莎仍想继续问，村边却忽然响起警钟，正在做事的人立即往能够暂避的地方跑。

克雷米回头听过，拿出虫草，准备像往常那样点燃，用烟将螳螂引开。莎莉叶听见他们说又来了，先向姐姐靠近一点，却又忍不住开口。

“这种魔兽，同一片猎场通常只有一对。你们一直把它们引走，它们以后还会回来。”

“那要怎样？”克雷米问。

“打倒。”她答得很快，抬眼看见草木间晃动的影子，脸色却又白了些，“若是这一对没了，就不用再一遍遍躲它们。”

燧火听她说得清楚，忍不住问：“你不是最怕这些？”

“就是因为怕，母亲才教过！”莎莉叶抓着布琪的手，“知道怎样对付，总比什么都不知道好！”

依莎已经站起来。燧火望向她，问能不能出手，会长立即点头，让克雷米带路。

对方却有些迟疑。

“村里拿不出佣金。”

“这次不收。”依莎答道，“先告诉我们，人从哪里退，魔兽在哪里。”

迪诺与鬼罹先在村中接应撤下来的居民，凯蒂也随人退到能躲避的地方。依莎六人拿起武器，跟着克雷米赶向英雄之道。离村边还有一段，众人已经听见坚硬肢体擦过地面的声响，两只巨虫一前一后，正堵在居民往来时会经过的路上。

燧火最先迎住逼近的一只。镰刃扫来，他立即偏开，身后的另一只却也转了方向，想从旁边将几个人截开。

“别全挤在前面！”依莎提醒，“米欧，看住右边！”

米欧举枪，将后面那只逼得稍停，依莎趁机绕到燧火侧面，接住又一次扫来的攻击。亚岁跟上，等两人让出位置，才把榴弹送向巨虫近旁，不让它们同时扑近。

布琪同妹妹守在稍后的地方。莎莉叶明明还在怕，却仍听着同伴的呼喊施术，每当虫体转近，她的手便紧一下，下一道攻击却没有因此全停。

第一只被逼退，另一只立即补过来，燧火没能趁势一直追，只得回身，替依莎让开退路。镰刃擦过近旁的石地，碎屑飞起，亚岁跟着退了半步，才重新找稳能开火的位置。

几人先将两只的攻势分开，再轮换着上前。米欧看见巨虫转身，立即提醒燧火避侧；姐妹的法术随之接上，让依莎有机会逼近。直到其中一只终于支撑不住，另一只失去接应，众人才得以集中力量，将它也击倒。

莎莉叶放下手，刚看了一眼倒地的虫体，又立即转过脸。

“别叫我过去看。”

燧火应了一声，让她先同姐姐站远些，自己与克雷米查看近旁。确认没有别的袭击者跟来，众人才返回村里，接上仍等消息的人。

克雷米告诉大家，两只螳螂已经处理，村民才陆续走出藏身的地方。有几个还没来得及放下的工具，被重新捡了起来，带来的粮食也终于能安静分下去。

依莎站着看了一会儿，没有因为眼前这件事办成，便说卧薪村往后都不必再担心。房舍仍旧，契约仍在，那些被送去外大地的人，也没有跟着这场胜利回来。

等同村民说过后续要留意的地方，众人才沿来路回车旁。天色已晚，凯蒂把留下的货袋收好，又告诉依莎，自己在城里听见守军传令：明日下午三时，树罗军将正式进攻钟塔。

依莎抬起头，停了好一会儿，才问日期有没有听错。凯蒂说得清楚，她便没有再追问，只将尚未整理好的东西重新列出。

“明天早上走。”

亚岁望向她，米欧也停了手。燧火等会长把东西放好，才轻声问：“还是不留下吗？”

依莎看过众人，声音比先前疲倦。

“我不喜欢巴尔的做法，可契约不能全当作废。该怎么改，还得问清城里的情况。”

她停了一下，又看向亚岁与姐妹。

“先把答应的事办好。今晚收拾一下，早点休息。”

没有人立即同她争。燧火看得出，她也不是说完便真能轻松，终究没有逼她当场换一个答案。

依莎回车内歇息以后，任务记录本仍摊在桌上。燧火收起时，看见要带亚岁回去、继续护送姐妹，以及设法向汉克报平安的几项，都还留在未完成的地方。

他将本子放到会长明早拿得到的位置，才转身去看车辆。钟塔的方向渐渐暗下来，车旁却还有行李要固定，明早出发以前，也仍得把每个人带着的东西一件件收妥。
