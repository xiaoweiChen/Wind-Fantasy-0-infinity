# 黑之船里的商议

久远制住众人以后，便让机械将他们押回黑之船，集中看守在饭间及相邻的舱室里。通往甲板和蔽天号的两处出口都被守住，任何人想离船，都得先经过她的准许。

如今，黑之船的舱窗外，海面已经暗过两次。

艾因靠着墙坐下，先将一杯水递给莉可。她接过去，向他轻轻点头，手指仍有些发酸。此前反复抵挡机械的消耗没有全缓过来，众人却至少已经能够坐起、走动。食物和饮水按时由机械送到，装在推车上的桶碗放下后，便沿原路返回蔽天号。

看守他们的，是守在两处出口的机械。

它们平时并不走近。只要有人越过通向两船连接处的那道门槛，金属手臂便会抬起，将人拦回去。西札尔试过一次，先说自己要查看小船有没有损坏，没有回应；再往前半步，一条铁臂便横到胸前。

他退回来，没有硬碰。

“它们不管我们在屋里做什么。”西札尔坐到桌边，“只守着出去的路。”

迪恩望向饭间旁的栏门。久远收走的兵器就锁在里面，外面同样有机械看着。可可提出想去查看动力，得到的答复是可以在看守陪同下去，但不能擅自离开黑之船。双子星号仍停在蔽天号的货舱里，与他们隔着两船连接处的守卫。

“她连我们的小船在哪里都知道。”梅鲁说道。

“那么大的船，藏不住。”西札尔答道，“知道在哪里，倒也省了我们找。”

梅鲁看了他一眼。他仍有心情把话说得轻松，手却一直停在桌沿，慢慢划着刚才走过的方向。

千语坐在门边，黑曜不在身旁，她的目光便不时往存放兵器的地方移。费特与十三各自试过屋里另一扇门，后面只通向一间没有外出口的小储物室，装的是布与空桶。

艾因听完，先问可可，黑之船还能不能动。

“动力还在，船首卡着。”可可答道，“得先拆开夹住船头的断梁，现在不能直接退。”

“萨米耶他们呢？”迪恩问。

“都在下面照看动力，没有新的伤亡。”可可答道，“布琪和莎莉叶在旁边的休息舱，还没缓过来。”

说到姐妹，可可的声音轻了一点。众人被押回来时，她才看见两人已经累得站不起来。她给姐妹送过水，临走时莎莉叶还靠在布琪身旁，抱着玩具没有说话。

久远在这时走了进来。

守在连接处的机械向旁让开，她从蔽天号走进黑之船，沿通道来到饭间。艾因站起，迪恩也从桌旁转过来。久远没有让看守逼他们坐回去，只问食物是否已经送到。

“把看守撤走，让我们离开。”迪恩说道。

“让你们会再来阻止我吗？”久远反问道。

“我们来时就没打算替浮士德进攻晶耀。”艾因说道，“你把人关在这里，外面照样在死人。”

久远看向他，神情没有因为这句话改变。远处传来炮声，她转向舱窗，让众人能够看见岸上连成一片的烟。

迪恩向前一步，门旁的机械便转过来。久远抬手，让它停住。她看着这个曾经直面绿之意识的青年，语气比刚才稍缓。

“迪恩，你应当知道，那种存在不会因为人请求，就停止自己想做的事。”

“所以你也要学它？”迪恩问。

久远没有接这句。她只说自己还在等，等一个迟迟没有露面的存在。至于它是谁、为什么必须让这场战争继续，她都没有再讲。

迪恩还想问，久远已经转身。舱门重新合上，守卫恢复原来的站位，刚才那点能够走出去的空处也消失了。

梅鲁在桌旁坐下，忍不住握紧了拳。

“她说不想伤人，外面那些又是什么？”

没有人能够替久远回答。

艾因来到窗前，隔着远处的烟，看不清晶耀城还有多少地方完好。他曾在那里生活，也曾被迫离开；此刻想到的却是希亚、留在城里的熟人，还有早已没有能力再逃一次的普通人。

莉可走到他身旁。他回过头，才发现自己一直绷着肩。

“先找出去的办法。”她轻声说道。

艾因点头，握了一下她的手。

下午，可可获准离开饭间，先去下层查看动力，又提出想到蔽天号那一侧检查卡住的船首。久远让一台机械跟着，准许她走到连接处外侧的支撑旁，检查后便得返回。

可可跨进蔽天号的货舱，亲眼看见双子星号仍停在另一头，船身没有受明显损伤。通向它的路被几只大型货箱挡住，旁边也有机械。她没有向小船走，只把看得见的位置记下，检查过支撑便回到黑之船。

萨米耶正蹲在动力舱外，听见脚步，连忙站起。可可问过船首有没有继续松动，确认方才的检查没有漏掉新的损伤，才去旁边的休息舱看姐妹。布琪已经醒着，莎莉叶靠在姐姐腿旁，抱着史妮司，脸色仍很差。

“外面还在打吗？”妹妹问。

“还在。”可可在她们面前蹲下，“先歇着吧。”

布琪点头，又问其他人有没有受伤。可可将自己看见的说清，没有答应什么时候就能离开。莎莉叶听完，往窗外望了一眼，手指又抱紧了玩具。

“燧火在苍鹰号上。”她低声说道。

“凯也在那里。”可可答道，“他们知道我们还没有出来。”

她起身去看船首。扭曲的梁架仍紧紧咬住黑之船，维修者在能碰到的地方做过加固，暂时避免继续下沉。可可把检查结果告诉萨米耶，请他继续照看支撑，随后在机械陪同下回到饭间。船首仍卡着，看守也没有因此让出离船的路。

厌夜所在的仓门仍关着。

可可经过时没有停。跟在身后的机械离她不过两步，她只是伸手扶过那面熟悉的墙，便继续向前。仓内没有传来声音，人偶显然也知道，今天不能像往常那样开口。

回到饭间，可可把所见逐一告诉迪恩。西札尔也凑过来，听到双子星号没有损伤，先问登船梯是否还放着。

“还在。”可可答道，“守卫在货箱外侧。”

西札尔点点头，没有再问。

他们也试过其他办法。

十三拿着空杯走到门边，佯装失手，让杯子落地后滚过门槛。看守仍守在原处，等他想跨出去捡杯子时，才抬起手臂将他拦住。运水的机械推车经过，绕开杯子，照旧往前。

十三只得退回费特身旁。

“它一直守着门口，丢个杯子也引不开。”十三低声对费特说。

费特点头，将自己看过的另一侧告诉他。那里的门同样有人守，若硬冲，只能同时面对几台刚被重新接好的机械。就算冲得过，舱外仍是久远能够随时施术的地方，他们也无法把双子星号直接搬走。

“她看得见每一处吗？”十三低声问。

“不知道。”费特答道，“不能赌她看不见。”

西札尔听着，低声问可可，运水的机械多久会来一次。他没有因为看守动作单调，就把对方当作随便能够骗过的摆设。那股能将众人一下压住的力量就在相连的蔽天号上，任何办法都得先避开久远本人，而不是试着在她眼前跑得更快。

另一次震动以后，迪恩从窗旁回来，说地面的炮声更近了。艾因听到，立即站起来，走到门前要求见久远。看守没有回应，他只能沿门槛站了一会儿，又慢慢退回。

“这样等下去，谁也不知道外面会变成什么样。”艾因说道。

迪恩抬头看他。

“我也想出去。”他说，“但船上还有人。”

艾因知道他指的是谁，刚升起的急切便卡住了。他看向仍空着的两个位置，想起布琪与莎莉叶一路跟来时，还在商量回去以后可以接什么委托。

梅鲁没有替谁接话，只将那两只不用的杯子挪到一旁。她同迪恩经历过无法把所有人一次带走的处境，也知道艾因一旦看见有人被留在危险里，便很难先想自己能不能全身而退。

正因为都知道，稍后演出来的分歧才不必凭空找一个理由。

西札尔在桌沿上划下两个相近的记号，将其中一个向外挪了少许。梅鲁看见，终于明白，他整日没有急着去试门锁，是在找一条能让他们回来接人的路。

夜里，运送食物的机械将推车停在饭间门边，依次放下汤桶与碗。西札尔走过去，把汤提到桌旁。几人围近些，锅盖与碗筷的响动混进外面的炮声，压住了低声交谈。

西札尔低头分汤，忽然说：“你们两位团长，平时会吵架吗？”

梅鲁正准备拿碗，动作停了一下。

迪恩望向他。艾因先皱了皱眉，随即看见西札尔的手指在桶沿轻轻敲了两次，便没有立即开口。

“意见不一样，很平常。”迪恩说道。

“那就好。”西札尔把一碗汤递过去，“若从来不吵，这回还得多练一练。”

费特向门口看了一眼，十三便起身搬凳子，挡住看守能直接望来的那一点空隙。机械仍停在门旁。众人往桌边靠近，西札尔将声音压得更低，继续说下去。

“它们拦人，是因为人想出去。若屋里先打起来，你猜守卫先管哪件事？”

艾因抬眼。

“你想让我们动手？”他问。

“演得像一点。”西札尔答道，“可以见血，避开要害，别伤到旁人。我和韩德尔试过，越是先认定我们各有主意的人，越容易只看见他愿意相信的那一面。”

迪恩看向桌上摊开的粗略路线。

“黑之船退不了。”他说。

“所以得先有人出去，把这里的事说清楚，再带能修船、能接应的人来。”西札尔说道，“让她以为我们真的待不下去，把两团分开。只要利奇曼被押到蔽天号那边，就有机会靠近双子星号。留在休息舱的姐妹，由你们照看。”

屋里安静了一瞬。

梅鲁望向可可，后者也正抬头。两人都明白，若双子星号能走，留下的仍是被卡住的黑之船和黑之团。魔女姐妹如今连走到货舱都费力，更不可能靠她们再撑着法术带所有人离开。

艾因先开口：“我们不能只把你们留在这里。”

“你回去，才有人来。”迪恩答道，“韩德尔不知道这里怎样，他不会让所有船一艘艘撞进来。”

西札尔看了两人一眼，将碗放下。

“这句话倒可以留到动手的时候说。”他说，“你急着出去救人，他不肯扔下自己的船和同伴。都是真的，只把火气放大些。”

梅鲁的手从碗沿滑下，慢慢按在膝上。她明白这是安排好的，却仍觉得心里沉。迪恩看出她在想什么，向她轻轻点头。

“你是利奇曼的副团长。”他说，“跟艾因走，把消息送到。”

“我们会回来。”梅鲁答道。

“我知道。”

莉可把分好的汤送到近旁，没有插话。她想过另一个能够呼唤的名字，目光却碰上门边始终没有移开的金属身影，又转回身旁同伴。这里没有能够避开所有人的空处，她不愿在众目睽睽之下召来神使。眼下既然找到了路，她便先同大家把这条路走通。

可可等运送食物的机械退出门外，才将脚边那包旧件推到桌下。她检查船首时，从修理柜底取出过一柄备用短刀和一把短枪，裹在旧布里带了回来。看守只盯着她有没有走向双子星号，没有翻动那包沾着油污的东西。

艾因接过短刀，迪恩则检查了枪膛，随后各自将兵器收在衣侧。两人惯用的武器仍锁在栏门后，眼下这两件已经够用。

“桌子后面是空器具间。”可可低声告诉他们，“别往休息舱那边打。”

迪恩点头，艾因也看清了那一侧的位置。

西札尔等众人吃过饭，又将经过压低声音说了一遍。谁先开口，谁去拦，谁趁看守转向时挪到门旁，都得同各自原来的习惯接得上。可可说起从饭间跨进蔽天号、再去货舱要经过的那道门，西札尔便把原先准备的顺序改了半步。

他们没有反复练习给门外看。

十三照常收碗，费特去水桶旁洗手，千语仍坐回原来的位置。梅鲁将凳子挪开时，故意比先前重了一点。艾因转头看她，她便当着看守的面问，究竟还要在这里等多久。

艾因没有立即答。

迪恩也从桌旁抬起头。几个人的目光在半明的灯下碰过，随即各自移开。门外的机械没有反应，仍按原有的指令守着出口。

夜更深时，船身又震了一下。

西札尔靠在墙边，像是终于睡了，手掌却压着膝上的一小块布。他在等机械下一次来收空桶，也在等外面的炮声再密一些。

艾因望着对面的迪恩，慢慢将方才藏起的那一点歉意收好。明日若要让别人相信，他们就不能总用已经商量过的眼神相看。

窗外又一道火光升起。

这一次，谁都没有走过去看。
