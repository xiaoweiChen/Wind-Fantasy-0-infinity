# 涵洞里的引路人

莎莉叶轻轻叫过姐姐，又闭上了眼。布琪立即俯低，听见妹妹仍在呼吸，才慢慢松开攥紧的手，让她能靠得舒服一些。

来人将那颗水晶球移到眼前。球内的绿光仍在缓缓旋转，球面上的银纹却已严密合拢。他又看了一会儿莎莉叶的掌心，确认没有新的光涌出，才让球缩小，收进袖中。

平石四周的银色光纹渐渐暗下，却没有消失。光点仍被法力隔在外侧，根须也已经退回水边，偶尔还有一两束缓慢挪动，却没有再朝女孩伸来。费特与十三仍守在外侧，等来人示意可以放下兵器，才退回近旁。

聆烨接过十三递来的布，替莎莉叶擦去额头的汗，又将史妮司放到她手边。女孩摸到熟悉的玩具，才重新睁眼，先看了看自己的手腕。

根须留下的浅痕仍在，手指却已经能听她使唤了。

“姐姐，刚才那些光一直往里面来。”莎莉叶低声说，“我想停下来，可怎么也停不住。”

布琪低头将她搂紧。她还能清楚地记得，妹妹才在不久以前笑着答应十三，遇上难走的路，可以再用魔法帮忙。那时她也高兴，谁都没有想到会变成这样。

“现在好些了吗？”布琪轻声问。

“嗯。”妹妹看向石台外面，“可是，那些光还在。”

“附近的光点已经被我用法力暂时驱散了。”来人答道，“先在这里歇着。”

布琪点头，接过琉特找回的水囊，喂妹妹喝了一点。莎莉叶咽得很慢，喝过以后又看看掌心，见那里没有亮起来，才让紧绷的肩膀稍稍放松。

姐姐一手托着水囊，一手替她理开沾在脸侧的头发。她自己的魔力仍很安稳，方才挡根须的法术也能顺利收回；越是这样，她越不明白，为何同行一条路，妹妹却险些倒在这里。

琉特在旁边收起两姐妹落下的包，聆烨则坐到布琪身旁，帮着扶稳莎莉叶。公主望向刚才取水的地方：木桶仍在，水也仍沿原路流过，几束根的末端却已经留下枪击的裂口。她先前只顾看那片明亮的绿光，连它们何时靠近都没有发现。

费特等对方查看过莎莉叶的情形，才开口问道：“怎么称呼？”

“我叫笛敏特，是世界树的守护者。”来人答道，“方才察觉这边的魔力异常，我就循着根系传来的波动找了过来。”

十三望向从石台旁延伸出去的根。

“是她的魔力失控，你才察觉的？”十三问。

笛敏特点头，先看过莎莉叶的脸色，再将目光移向两姐妹。

“你们是月之魔女一族？”

布琪迟疑了一下。莎莉叶却先往姐姐身旁靠，望向他的眼神重新多了几分戒备。费特见状，便站到石台外侧，替姐妹遮住一部分从深处投来的亮光，没有替她们答话。

“是。”过了一会儿，布琪才轻声承认。

“你们以前来过这里吗？”笛敏特问。

布琪摇头，告诉他，自己与妹妹只听母亲说过，也读过几本旧书。方才一路走来，她们都觉得魔力恢复得很快，后来妹妹却开始发热，掌中自行涌出力量。

“我倒一直没事。”布琪低声说。

笛敏特听完，望了一眼姐妹方才经过的位置。那边有几束新接上的细根，浮起的光比外缘浓得多。他俯身拨开其中一处，看见亮色仍在反复涌过，眉间便沉了下来。

“这里最近有了变化。”他说，“原本分散的供养，有些又接到一起。这一处比从前更强。”

“可妈妈说，魔女能在这里恢复魔力。”莎莉叶抬头，声音里还带着后怕，“书上也是这样写的。”

“能够恢复，不过也要选合适的地方。”笛敏特指向石台外那些浮动的光点，“那些就是这里的孢子。刚才你们走到的地方，孢子比外缘密得多。”

女孩低头看着自己的手。刚才让她高兴的温暖，也正是后来最先使她害怕的东西。她从没有想过，自己平常觉得很自然的恢复，会在这里变成一件无法收住的事。

笛敏特在石台外侧坐下，让姐妹不必一直仰着头。

“孢子同这里的根相连，能补充力量，也会激起魔女身体里的魔力。”笛敏特说道，“年长的魔女吸收月光的能力减弱，才更需要借助这里。只是，同样的孢子，落在不同的人身上，反应未必一样。”

“可我们一直在一起，只有妹妹这样。”布琪低声说。

笛敏特的目光在姐妹脸上停了片刻。

“魔女的年岁，未必像看起来那样相近。”他说得很轻。

布琪微微一怔，低头看了看仍靠着自己的妹妹。笛敏特已经收回目光，俯身查看水边退去的细根，没有接着往下说。

莎莉叶也望向那些根，手指不自觉地缩进姐姐掌中。

“它们刚才为什么要缠住我？”妹妹轻声问。

“世界树能感受到内部的魔力变化。”笛敏特答道，“哪一处聚集得太多，根系就会吸收，再将力量送往别处；哪里不足，也会通过根系释放魔力，补上缺少的部分。”

他拨开垂在石边的一束细须。里面有淡淡的光缓慢流过，顺着相连的根延伸到水下，更远处几束原本黯淡的细须，随之透出了微光。

聆烨顺着那点亮色看过去，直到它消失在根后的暗处。

“所以，它们不是为了抓住她？”公主问。

“刚才她周围的魔力突然聚得太多，根就伸了过来。”笛敏特看向莎莉叶手腕的浅痕，“它们在调节树内的力量，却不会顾及她能不能承受。若放任它们缠下去，仍会伤到她。”

莎莉叶将手腕藏到袖下。布琪没有松开她，听见根须挪动的轻响，仍先向水边看了一眼。

“世界树这样庞大，各处消耗的力量不同，得到的供养也不同。”笛敏特继续说道，“根系不断吸收、释放，让魔力不至于都挤在一处，也不让另一些地方长期枯竭。它能维持这么久，靠的也有这份平衡。”

十三看向他方才收起水晶球的衣袖。

“你把她多出来的魔力收走，根才退开？”十三问。

笛敏特点头。

“水晶球能隔绝里面的魔力。”笛敏特解释道，“根系感受不到那股异常的力量，就停止靠近了。”

费特望向自己击断的细根。方才只要莎莉叶换一个位置，旁边便会有新的根追来；直到那颗球表面的银纹合拢，它们才慢慢退开。他将枪口放低，仍留在能看清水边的位置。

布琪将妹妹的手轻轻握住，掌心已经不再灼热。莎莉叶听懂了，目光却仍停在水边。那些光在远处明明很美，方才也曾让她觉得舒服，如今只要看见稍亮的一簇，她便不自觉地往姐姐身旁缩。

“以后还会这样吗？”妹妹轻声问。

“我先用法力驱散了附近的孢子，再抽走多余的魔力，你才缓过来。”笛敏特看过她的手，“孢子只是暂时散开了，今天别再往密集的地方走。”

布琪点头，将妹妹方才没能喝下的水重新递给她。女孩这次能自己握住了，却只喝一小口，便停下来看看手有没有再发光。

姐姐看在眼里，便把史妮司放到两人中间，伸手替她托住水囊底部。

“我陪你看着。”布琪低声说。

莎莉叶终于又喝了一点，紧绷的肩慢慢放松。琉特坐到外侧，将姐妹放在路边的包收拢，给她们留出能够靠稳的位置。

聆烨在近旁听着，等姐妹缓过一阵，才问道：“这里就是茧之座？”

笛敏特抬头，向四周看过。

“已经进到里面了。你们来时的窄路通到外缘，眼前这一片是靠近地下水流的涵洞。再往深处走，根会汇得更多，连接的地方也不同。”

他将几条能够看见的走向指给公主。根并非简单地围成一间屋，石壁与水路把宽阔的地下分成许多相通的地方，有些可以绕行，有些早已被重新生长的部分遮住。他们此刻看见的绿光，仍只照出其中一侧。

聆烨顺着望去，终于将方才分不清远近的景象，与一条条实际可以行走的路接在一起。孢子聚集的地方不全相同，有些根只露出干硬的表面，旁边却可能仍有水流经过。眼前这处照得很亮的地方，也不能因此认作整个茧之座最重要的位置。

“世界树的水和力量，都经过这里？”她问。

“这里连接着许多根系。”笛敏特答道，“过去维持的联系很多，如今有的断了，有的还在用，也有新长出来的。不能只看哪一处最亮，就说它现在一定在供给哪里。”

公主想到带在身上的改渠图。地面的村民看见泉水恢复，便以为水会照原来的路走；来到地下，他们也很容易把一片绿色，当成已经恢复完好的证明。她将那个念头收住，只在图上先记眼前能够认清的位置。

十三则望向来时的石路，问起下层那些使人看见幻象的石头。

“我们找路的时候，看见有些地方像镜子。她和琉特掉到下面以后，一直绕不出来。”他说。

笛敏特听完，向落入下层的两人看过。

“你们遇到的是幻壁，属于世界树形成的幻境。”他说，“它会重现闯入者心里的恐惧和悲伤，让人看见最不愿面对的影像，借此迫使他们远离，保护自己。”

聆烨握着水囊的手指停了一下。琉特也垂下眼，原本还想问的话，到了嘴边又收了回去。

“进去以后，我们为什么看不见对方？”过了一会儿，琉特才问。

“幻壁会把进入其中的人隔开。你们各自面对自己的影像，既看不见彼此，也听不见、感知不到对方。”笛敏特答道，“不过，出口是同一处。只要能坚定自己的信念，不再被那些影像牵住，就能走出来。你们能出来，已经说明了很多了。”

琉特想起自己沿着亮石找过的那几条缝，这才明白，为什么最后又在原处等到了公主。聆烨听着，慢慢将手中的水囊放稳，却没有接话。

“至于里面看到了什么，也只有你们自己清楚。”笛敏特说道。

两人短暂地对视了一眼，又各自移开目光。聆烨的神情有些僵硬，琉特则低头理着袖口，手指在沾着泥的折处停了许久。谁也没有将看见的东西说给大家听。

十三看过两人，也没再追问。笛敏特也只确认他们离开以后，眼前已没有再出现重影，才起身看了看外侧的根，将通往上层、可以避开幻壁的那段路指给众人。

聆烨将路线记在纸上，写到转弯时停了停，像仍在想着别的事。她很快收住笔，把纸交给琉特核对，目光只停在眼前能够认清的道路上。

费特一直等在石台旁。见莎莉叶已经能自己接水，布琪也能腾出手替妹妹收好外衣，他才问笛敏特，姐妹接下来该留在哪里。

“先在外缘歇着。”笛敏特指向平石另一侧较暗的通路，“从这里走，能避开刚才那片密集的孢子。今天别再往深处去了。”

莎莉叶看向洞内，神情有些复杂。她想过来到这里以后，终于能像古籍里写的那样，看一看魔女与世界树共同生活的地方。可此刻她只想让手重新安静，想喝一口水时，不必先担心自己会不会又弄出无法收住的光。

“我不往里面去了。”妹妹轻声说。

“我陪你。”布琪答道。

笛敏特陪姐妹又等了一阵，确认莎莉叶的魔力没有再次失控，才起身查看周围。费特与十三在旁照看，琉特则沿着他指的路走过一段，认出了方才费特提灯下来的转弯。从这里绕上去，就能接回四人走过的正常通道，不必经过幻壁。

“我先在这里陪她们。”琉特回来后向公主说道，“等她们缓过来，我送她们回车。”

聆烨点头，把路上的转弯同他核了一遍。她在图上标出落下的位置，将那片不宜再走的石路圈到一旁，留下真正能够往返的通道。

笛敏特回到石台边，看过莎莉叶的情形，才转向仍等在一旁的费特。

“你们来茧之座，是有什么事？”笛敏特问。

“找两个人，艾因和莉可。”费特答道。

听见这两个名字，笛敏特抬眼看向他。

“你的朋友吗？”

“我叫费特。”费特说，“我们已经找了他们很久。”

“我叫十三，是陪他一起来的。”十三接过话，“泉区有位老人，几年前送过他们到洞口，给我们指了路。可入口被树根堵住了，我们直到今天才进来。他们还在这里吗？”

笛敏特听完，朝众人微微一笑。

“真巧，我也认识两位朋友，一位叫艾因，一位叫莉可。”笛敏特说道，“要不要一起去见见他们？看看是你们要找的老朋友，还是两位新朋友。”

费特望着笛敏特含笑的脸，原本紧皱的眉头稍稍舒展，眼中却仍带着急切。他握着衣带的手松了一些，轻轻点头。

“带我们去吧。”费特说。

笛敏特含笑应下。十三也跟着松了口气，向费特靠近些。一路打听来的零散消息，终于有了可以继续往前走的去处。费特还有许多话想问，却没有再站在这里追问下去，只收好随身的东西，等着同伴准备动身。

聆烨转向姐妹。布琪正替妹妹把外衣拉好，听见笛敏特愿意带路，也抬头望来。公主告诉她们，自己会同费特、十三去见人，琉特留在这里，等两人能走以后，便按方才认清的路回车旁。

“知道了。”布琪轻声答应。

莎莉叶抱着史妮司，看向笛敏特。

“刚才，谢谢你。”她说。

笛敏特点点头，却没有立即走。他从袖中取出那颗缩小的水晶球，托到女孩面前。绿光安静地浮在球内，银色的纹路沿表面绕过一圈，才渐渐停住。

“这个魔法球送给你了。”笛敏特说道，“你要好好收着，照顾好妈……”

他说到这里，目光向布琪一转，唇边的笑意稍稍停了停。

“照顾好你的姐姐。”笛敏特轻声改口。

布琪抬起眼，与他对视了一瞬，又低头替妹妹理好袖口。莎莉叶的目光还留在水晶球上，抬头时，脸上有些不敢相信。

“真的给我？”莎莉叶问。

“嗯。它是一件能收存魔力的法器。里面这些，也本来就是你的力量。”

女孩看向姐姐。布琪轻轻点头，伸手托住妹妹的手背，陪她接过那颗水晶球。球落在掌中，比看起来稍重，触手却很温和。她试着转了转，里面的绿光也随之一晃，映亮了仍带着泪痕的脸。

“谢谢。”莎莉叶轻声说，这回没有急着将手收回袖里。

布琪替妹妹拿过水囊，看着她把水晶球妥帖收好。笛敏特又确认过女孩的脸色，才起身带路。

费特跟在后面，经过那只取水的木桶时，终于没有再停下来猜它是谁留下的。笛敏特指过根后的转弯，告诉他们，木桶是艾因平时取水用的，他常从这里来回，前面的一段窄路通向病榻所在的地方。

聆烨边走边看。不同于方才使人几乎迷失在绿光里的宽阔涵洞，这边有些根被引到两侧，脚下也清理过。布晾在不容易被水滴沾到的地方，空杯放在石台边，几件生活用具被收在干燥的一角。它们没有使地下变成真正的家，却使人在漫长的照护里，仍能找到一处放水、换布、坐下等候的位置。

转过最后一束低垂的根，笛敏特放慢脚步，朝里面叫了一声。

“艾因，有人来找你。”
