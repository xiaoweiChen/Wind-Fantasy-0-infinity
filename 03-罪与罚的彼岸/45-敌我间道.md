# 敌我间道

西撒醒来时，先听见了窗外的脚步声。

有人在廊下交谈，声音隔着门，听不清内容。他试着转头，肩背的痛楚便使动作停了下来。身下是床褥，身上的伤也已包扎过，雪狼崖的风雪却仍像留在记忆里。他记得蕾菲娜走来，记得帕鲁玛叫自己不要靠近，随后便是迎面而来的攻击。

床边的椅子轻轻响了一声。

“醒了？”

九音俯身看着他，等他的目光终于定下来，才松开一直扶在床沿的手。

“九音……这里是哪儿？”

“雷那。”

西撒想撑起身体，九音立即扶住他的肩，让他慢些。伤处被牵动，他吸了一口气，等那阵痛缓过去，才借着她的手靠稳。

“我怎么会在这里？我和帕鲁玛明明还在雪狼崖——帕鲁玛呢？”

“她也救回来了，正在另一间屋里休息。她恢复得比你好，已经问过你好几次了。”九音将水递到他手边，“你已经昏睡三天。”

“三天？”

西撒低头看向缠在身上的绷带。这三天里，军队不可能一直停在原地，其他人的去向，他却一件也不知道。

“你在那里找到我们的？”

“嗯。看见你们倒在地上，我便让人送回来了。”

九音等他喝过水，才接着说：“帕鲁玛醒来后，已经告诉我，是蕾菲娜袭击了你们。她还说，那时候蕾菲娜身上的气息不太对。你与她交手时，也有这种感觉吗？”

西撒握着杯子，想起帕鲁玛倒下以前，自己竟还在问蕾菲娜什么时候回来。

“有。我起初以为她是来归队的，没有防备，等帕鲁玛提醒，已经来不及了。”西撒稍稍挪动手臂，伤处仍在发疼，“她的剑技里有一股不寻常的气息。我以前见过她出手，那时候没有这种感觉。”

“会不会是原罪徽章？”

西撒抬起头。

“我还不能确定。”九音说，“只是蓝斯也因为原罪徽章受了伤。”

“蓝斯？谁伤了他？”

“乌德斯。他用了炽焰徽章，蓝斯为了救人，挡了他的攻击。这些是幽弥回来告诉我的。凯琳已经把蓝斯送到尼鲁，正在那里照顾他。”

西撒不自觉地握紧了手里的杯子。

“炽焰不是已经封好了？”

“所以才要弄清楚，为什么又会出现在乌德斯手里。”

九音没有把对蕾菲娜的怀疑也说成定论。帕鲁玛与西撒都察觉了异样，却没有像幽弥那样，亲眼看见乌德斯使用炽焰。可两场袭击发生在同一处战场，受伤的又都是圣焰自己的人，已足以使她不安。

“为了打赢这场仗，圣焰王也许已经不在乎力量从哪里来了。”她低声说。

西撒没有接话。凯琳在封印时怎样反复练习，安洁妮又为了最后一次施术付出了什么，他都还记得。如今他们却倒在本应被封住的力量之下。

九音从他手里接过空杯，放到床旁。

“先歇一歇。别急着把这三天的事全问完，明天一早，我义兄还要见你。”

“冷夜王？”

“等你和帕鲁玛能走动了，我带你们过去。”

西撒望向门外。这里没有人来审问他，也没有人要求他交代圣焰的军情。九音替他把被角放好，临走又叮嘱了一遍，不舒服就叫人。他应了一声，直到门轻轻关上，仍没能把眼前的照料与自己出征时所想的敌国放到一起。

第二天，帕鲁玛先到了他的房间。

她进门便打量西撒，看见他已经穿好外衣，才走近检查他肩上的衣料有没有压住伤处。

“慢一点，没人叫你刚醒就去打仗。”

“你呢？伤还疼吗？”

“还有一点，不过已经能自己走了。”帕鲁玛替他理好衣服，往门口让开，“倒是你，别逞强。走吧，九音在等我们。”

两人随九音穿过宫中的廊道，来到内侧一间僻静的书房。西撒走得比平日慢，九音也没有催。等门前的守卫通报过姓名，她便领着两人走了进去。

冷夜皇帝坐在案后，面前还放着未收起的军报。西撒停下脚步，与帕鲁玛一同行礼。

“西撒·赤红·圣亚里昂、帕鲁玛·艾莉卡，参见冷夜王。感谢您的救命之恩。”

“不必多礼，坐吧。”

九音待两人入座，便转向屋内侍候的人，又将门边的侍卫叫到近旁。

“你们先退下。陛下有事要与他们单独谈，未经传唤，不必进来。”

随从与侍卫应声退出，沿廊道走远。九音确认再没有旁人留下，也退出书房，轻轻带上了门。

屋里只剩下三人。皇帝将军报合上，目光才落到西撒身上。

“你大概也在想，我为什么肯救你们。”

西撒没有否认。

“我们才刚率军攻打过冷夜。”

“我知道。救回你们，等伤养好了，还可能要再应付你们带来的军队。”皇帝说到这里，语气却缓了些，“可毕竟做过你们的老师，要我见死不救，也实在做不到。”

西撒抬起头，目光从皇帝手边的军报移到了他脸上。

“老师？”

眼前分明是曼菲斯特的面容。冷夜发出的宣告，他也早已听过：韩德亲王已经死在沙达那。可这句话说出口时，对方看他的神情，却使他想起了另一位教官。

“在洁拿鲁的斗技场，你不是还以单骑的方式，赢过萨塔鲁多吗？”皇帝问。

西撒望着那张脸，终于站了起来。

“韩德教官？”

帕鲁玛猛地转向案后。韩德没有再让他们猜，点了点头。

“是我。现在站在你们面前的，并不是真正的曼菲斯特。”

“那真正的冷夜王……”帕鲁玛的话停在一半。

“大哥已经死了。”韩德将手按在合拢的军报上，“死在杰奥斯的阴谋里。”

屋里安静下来。西撒想起凯琳听见韩德死讯以后的样子，也想起圣焰以这场冲突为由发出的出征命令。两国都在谈论死去的人，可他们至今连死者究竟是谁，都没有弄清楚。

“所以，您才用他的身份继续统领冷夜？”

“四族能放下旧怨，合力建立这个国家，大哥的分量无人能够替代。外敌就在眼前，若他的死讯再使各族分裂，冷夜便很难守下去了。”

韩德将交换面容的事说给两人听，没有再用公诸国人的说法搪塞他们。说完，他看见西撒还站着，便抬手示意。

“先坐下。伤还没好，不必一直这么拘礼。”

西撒慢慢坐回去。知道教官活着，他本该高兴，可韩德仍顶着另一张脸坐在那里，案上的军报也没有少一份。那场在他们不知道的地方发生的死亡，已经把所有人推到了今天的位置。

“韩德教官，我还有一件事想请您答应。”

韩德看了他片刻。

“你想回圣焰。”

帕鲁玛转过头，西撒则点了点头。

“是。我得回去弄清楚，有些事为什么会变成这样。”

韩德没有立即说话。他本来就知道，救回来的学生并不因此属于冷夜，只是听见西撒亲口提出，仍难免有些失望。

“我原本也想过，或许能留下你。”他终于说，“可把你拘在这里，对谁也没有好处。你们要走，我准许。”

西撒起身致谢。

“您的身份，我不会泄露。”

帕鲁玛也应下保密。直到离开书房，她才拉住西撒，在不妨碍人来往的廊边停下来。

“你真的还要回去？”

“嗯。”

“乌德斯拿原罪徽章伤了蓝斯，蕾菲娜又袭击我们。若这些真是圣焰王默许的，那我们当初封印徽章，到底是为了什么？”帕鲁玛看着他，“这样的君主，你还要替他效命？”

“我也想知道答案。”西撒说，“所以才不能只留在这里猜。徽章是谁解开的，蕾菲娜为什么攻击我们，蓝斯如今怎样了，我得亲自去问。”

帕鲁玛没有再劝，只陪他往外走。经过街道时，两人听见有人在屋檐下谈话。一名女子抱着刚买来的东西，望向往城门赶去的兵士。

“原以为原罪劫结束，就能安稳过日子。怎么又打起仗来了？”

旁边的男人将声音压低了些。

“圣焰想要北方，又不是一天两天了。如今有了出兵的理由，哪肯轻易收手。”

“可再打下去，我们什么时候才能不用这样担惊受怕？”

西撒走慢了一步。女子没有留意他们，只将手里的东西抱紧，转身进了屋。

“西撒？”帕鲁玛回头。

“我还在想蕾菲娜的事。”他收回目光，“她既然已经回到圣焰，为什么要对同属圣焰的我们下手？”

帕鲁玛也答不上来。她只记得姐姐逼近时的气息，以及自己提醒以后，仍没能躲开的攻击。

两人各自想着那场交锋，一时没有再说话。

而在圣焰一方，蕾菲娜也没有向另一个人解释清楚。

艾尔札克先前被当作战败的罪人拘押，如今，蕾菲娜却给了他离开的机会。他不明白她为什么这样做，想问清楚，她却只说，所有的事都经过了周密安排，连她放走他，也在其中。

“我不能告诉你原因。”

艾尔札克看向她，等她继续。

蕾菲娜避开了追问，只留下最后一句请求。

“别再回圣焰了。”

艾尔札克还想追问，她却没有再说下去。他只得先行离开，走出几步，又回头看了一眼。蕾菲娜仍站在原处，没有再叫住他。

几日后，在雷那供西撒与帕鲁玛养伤的住处，收好的行囊也已放到了门边。两人准备动身返回圣焰。

西撒穿好外衣，活动了一下肩臂。用力时，伤处仍有一点牵扯，寻常走动却已经不碍事了。

“差不多了。”他转向帕鲁玛，“东西都收好了吗？”

“收好了，药也放在里面。”帕鲁玛将行囊拢到一处，“先去向韩德教官和九音辞行，再回来拿。”

西撒点头。两人离开住处，沿着已经走熟的街道往王宫去。经过先前听见百姓交谈的地方时，西撒又望了一眼那处屋檐，想着临走前，总该好好谢过这些天照料他们的人。

一阵急促的号声却从城门方向传来。

街上的人纷纷停步。一队兵士从前方路口赶过，领队的人叫众人让开道路，随后又有运送箭矢的车子跟上。方才还在招呼客人的店主探头看了片刻，便催家人将摆在外面的东西搬回屋里。

西撒与帕鲁玛退到路边，让车子先过。望向城门时，他们看见守军正陆续登上城墙，另有队伍整装出城，街上的交谈声也渐渐被传令的呼喊盖住。

“有敌军过来了？”帕鲁玛低声问。

西撒尚未回答，一名宫中的传讯兵已经沿街寻来。他看清两人，赶忙停下行礼。

“西撒公子，陛下正派人找您，请随我进宫。”

“是圣焰军？”西撒向城门示意。

“是。他们正在向雷那发动总攻，陛下有急事与您商议。”

西撒与帕鲁玛对视了一眼。刚才还在商量的归程，此刻谁也没有再提。两人随传讯兵加快脚步，越过正向外传达军令的人，赶回宫中。到了书房门口，西撒看见韩德已经站在展开的地图旁，身边的人刚交完一份军报。

“九音呢？”西撒先问。

“和幽弥出城迎战了。”韩德指向图上逼近王都的路线，“蕾菲娜率领的部队离雷那最近。若她确实持有原罪徽章，单靠九音她们，很难挡得住。”

西撒看着地图，没有立即接话。

“我才答应让你走，现在又请你留下帮忙，确实有些强人所难。”韩德抬头，“但我还是想请你去支援九音。”

“您不怕我到了阵前，临时改了主意？”

“不怕。我相信你的为人。”

韩德没有再拿师生之情催他。西撒垂眼看着地图，眉头却迟迟没有松开。他才刚获准返回圣焰，如今若答应出战，便可能要将兵器指向自己熟悉的人。那些人会不会听他解释，又会怎样看待他的选择？

西撒嘴唇动了动，还是没有立即答应。可想起九音在床边扶住自己的手，他又无法就这样开口告辞。她没有先问救回来的敌将会不会替冷夜作战，便将他和帕鲁玛带离了雪狼崖。

如今，自己原本要回去查问的那些人，已经先到了她面前。

他望向地图上通往城外的道路，抿紧嘴唇，过了片刻，才重新抬起头。

“她们在哪里交战？”

“雪狼崖。”

西撒转向帕鲁玛。她已经走到他身旁，等着一同出发。

“那就先去把人接应下来。”她说。

韩德让人取来两人的兵器，再将出城的路线指给他们。西撒接过枪，试了试肩臂，伤处仍有些牵扯，握住枪柄的手却没有松开。帕鲁玛看见他的动作，低声提醒别只顾往前冲，他应下，两人便随前来带路的兵士向城外赶去。

越过城外的道路，风声渐渐盖住身后的喧闹。沿途不断有传讯的人迎面而来，带路的兵士问清前方的位置，才领两人离开大路，往雪狼崖靠近。还未看清交战的人，西撒便先听见了兵器相击的声音。

九音正守在崖道上。幽弥移到她侧后方，弓弦还绷着，几名守军则随着两人退开、接应，没有让逼来的圣焰兵冲散阵势。

拉法利翁就在对面。

“不愧是冷夜将来的领导者。”教官的声音越过交锋的空隙，“能在这里突袭，切断我军的道路，战术确实不错。”

九音挡开一次攻击，才答话。

“这也是你教过的。”

“可若你守不住，再好的战术也没有用！”

拉法利翁再度上前，九音不得不将注意力收回眼前。西撒握紧枪，沿冷夜兵让出的空隙赶过去，在下一轮攻击逼近时挡到了她身旁。

“西撒？”九音转过脸，随即看见跟来的帕鲁玛。

拉法利翁也认出了两人，手中的兵器稍稍一顿。

“我听说你已经死了。你怎么会在这里？”

“九音救了我。”西撒站稳，看向教官另一侧的蕾菲娜，“让我受伤的人，也正在这里。”

蕾菲娜握着剑，没有答话。

“为什么袭击我和帕鲁玛？还有，那股力量是不是原罪徽章？”

她的目光在两人身上停了片刻，仍然沉默。西撒正要再问，拉法利翁已经叫住他。

“这些事战后再谈。西撒，先回队伍来。现在该做的，是擒下九音。”

帕鲁玛向前一步。

“教官，圣焰王已经在用原罪徽章了，您难道不知道？”

拉法利翁没有立即回答。隔着两边尚未放下的兵器，他看了看自己教过的学生。

“我知道。但只要不过度使用，就能避免引发原罪劫。”他说，“有这份力量，战争便能更快结束。”

“更快结束……”西撒低声重复。

他曾经也这样算过：若抓住眼前的机会，早些攻下城，是否便能少死一些人。拉法利翁不是不明白原罪徽章的危险，只是在知道以后，仍认定可以承担这个风险。

“所以，乌德斯用炽焰对付自己人，也可以等战后再谈？”

“西撒，现在是在战场上。”拉法利翁的语气沉下来，“你要先分清自己的身份。”

九音仍站在西撒身旁。他若依照命令回去，就得先将枪转向刚刚救过自己的人，再等这场战争结束，去问那些也许再无机会回答的问题。

西撒重新握稳枪柄。

“教官，请恕我不能回队。我来这里，是为了协助九音击退你们。”

九音看向他，没有出声。拉法利翁却往前走了一步。

“你知道这意味着什么吗？你要与冷夜结盟，与圣焰为敌？”

西撒看着教官，终于点头。

“若一定要这样认定，我也没有别的话可说。”

拉法利翁脸上最后一点期待收了起来。

“那就做好觉悟。”

这一次，西撒没有再等熟悉的人先停手。拉法利翁逼近时，他迎住正面的攻击，九音随即从侧面接应，使教官不能只顾着将他压退。幽弥重新移开几步，为前面的两人留下活动的地方，一箭截住试图从旁冲来的圣焰兵。

帕鲁玛则一直望着蕾菲娜。

“姐姐。”

蕾菲娜抬剑迎来。帕鲁玛没有站着等她解释，先退到能够施术的位置，将逼近的攻势挡开。西撒看见这边交手，刚要转身，拉法利翁的下一击便到了近前；九音及时补到侧面，替他守住退路。

“先顾这里！”九音提醒。

西撒收回枪，挡住教官逼来的兵器。伤处在用力时扯得发疼，他没有再硬顶，顺着冲力退开，让九音接上。两人熟悉彼此的步法，却仍得时时提醒，才能在狭窄的地方换开位置。

拉法利翁没有让他们轻易喘息。西撒才站稳，教官便又压过来，逼他继续后退；可枪尖重新递出时，九音也已绕回能够出手的地方。拉法利翁不得不收住追击，转而应付两边。

另一侧，蕾菲娜几次试图越过帕鲁玛，都被法术截住。帕鲁玛不敢让她近身，又无法只凭一个人的力量将她逼退，只能一面移动，一面提醒幽弥留意侧后方。

幽弥的箭接了过来。蕾菲娜避开箭锋，重新站稳，却没有放下剑。

西撒在交手的间隙看见她。他原本一直防着上次那股突如其来的力量，可蕾菲娜始终只以眼前的攻势迎战。她并不肯让路，也没有使出他记忆中更危险的一击。

他还来不及细想，拉法利翁已经再度逼近。枪与兵器相接，西撒咬紧牙关撑住，直到九音将对方牵开，才重新退到帕鲁玛能够照应的位置。

几轮争夺下来，圣焰军仍未能越过他们。拉法利翁停在几步之外，望着自己的学生，呼吸也比方才重了些。

“真难缠。冷夜有了你，圣焰王要完成霸业，看来又得多费些工夫。”

西撒没有放低枪。拉法利翁却向雷那的方向看了一眼。

“不过，拖到现在，主军也该攻下王都了。”

九音脸上的神情变了。

“我已经截断了你们主军的道路。”

“我们只是前导，负责将你引出雷那。”拉法利翁说，“我和蕾菲娜将你留在这里，主军便有足够的时间攻城。”

九音看向身后。她若现在撤走，面前的敌军必定追击，可继续留在这里，又不知道王都还能守多久。幽弥察觉她的犹豫，刚要开口，帕鲁玛先握住了她的手臂。

“九音，先别乱。雷那不会有事。”

“可他刚才说——”

“报！将军，有急报！”

一名圣焰传讯兵从后方赶来。拉法利翁让近旁的人稍退，转身听报，手中的兵器却仍没有收起。

“说。”

“进攻雷那的部队失利了。”

九音抬起头，拉法利翁的目光则一下落到传讯兵脸上。

“怎么回事？”

“主军陷进了冷夜布下的口袋阵。傲鲁萨城内又出现军队，从另一面夹击，我军已经无法维持攻势。”传讯兵缓了一口气，继续报告，“爱西亚主教下令保全兵力，放弃傲鲁萨，退回沙达那。”

“连傲鲁萨也放弃了？”

拉法利翁望向远处，握着兵器的手没有立即松开。好不容易打通的道路，几次冒险才取得的城池，如今都已失去；继续留在雪狼崖，即使再困住九音，也换不回原先的战机。

他终于转过身，向部队下达撤退的命令。

“九音，这次是你赢了。”

九音仍没有走出阵前，只看着圣焰兵逐队退开。拉法利翁随队离去，经过西撒能看见的地方时，也没有再叫他回队。

蕾菲娜跟在后面。帕鲁玛望着姐姐，手中的法术直到对方走远，才慢慢散去。谁也没有得到多问一句的机会。

等最后一队敌兵退出崖道，幽弥才放下弓，抬手擦去脸旁的汗。

“真没想到，拉法利翁认真打起来这么难对付。你们要是再晚些，我可不敢保证还能挡多久。”

九音先让守军清点伤者、留意退军，才走回西撒面前。

“谢谢你。”她看过他身上的包扎，又低声问，“可你帮了我们，往后要回圣焰，便没那么容易了。”

西撒没有立即答话。方才他对拉法利翁说出决定时，便已经知道这件事；如今听见九音提起，才又想到城门另一边的父亲，以及那些仍在圣焰军中的同伴。

帕鲁玛先在他身旁站定。

“回不去就先不回去。总不能为了还能回去，就替动用原罪徽章的人作战。”

“就是。”幽弥将箭放回箭袋，“那我们以前费那么多工夫封印它们，又算什么？”

九音看了她一眼，没有反驳。西撒却仍望着蕾菲娜离去的方向，直到帕鲁玛叫他，才回过头。

“我在想，她刚才为什么没有用尽全力。”

帕鲁玛顺着他的目光望去。

“姐姐？”

“上一次她突然袭击，我们连招架的机会都没有。若那真是徽章的力量，今天为什么始终不肯用？”

没人能回答。西撒也无法只凭一次留手，便将自己与帕鲁玛受过的伤当作没有发生。他只是越来越难相信，蕾菲娜做的一切，都只为了替圣焰夺下冷夜。

九音见他久久没有挪步，便走到近旁。

“先回去吧。伤也得重新看一看。”

西撒点头，收回了枪。帕鲁玛走在他身旁，幽弥则留下与守军交代后续，约好稍后回城会合。

回到雷那以后，两人才听全了另一边的战报。韩德在王都布下的防御挡住主军，又以调兵使圣焰失去继续占据傲鲁萨的机会；冷夜军已重新控制城池，双塔也再次成为拱卫王都的屏障。

这一战终于让冷夜缓过一口气。西撒却没有再向韩德提出返回圣焰。他留下来，先帮助重新安排防守；至于那些还没有问清的事，只能等下一次面对故人时，再亲口去问。
